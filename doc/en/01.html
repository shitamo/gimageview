1. Introduction

1.1. What Is This?

GImageView is an image viewer that runs on the X Window System, under development to break through the hopeless situation of viewing huge numbers of images (and movies).

This version (0.2.27+gtk4) is a port of GImageView 0.2.27 to GTK 4. It has been tested on the X Window System (X11). On Wayland, embedded movie playback with the MPlayer and xine plugins is not possible.

It is basically an image viewer, but since version 0.1.1 it also implements simple file operations by drag and drop (image management functions). Since 0.2.3 it also supports movie playback using xine or MPlayer (the GTK 4 version also supports GStreamer). The susie plugin, which was supported experimentally in 0.2.3, has been removed in the GTK 4 version.

1.2. Features

GImageView has the following features.

  • Opening multiple directories at the same time, switching thumbnail views with tabs

  • Recursive loading of any directory; the root can be set

  • Low memory usage

  • Designed with careful consideration for use from the command line

  • Simple and flexible interface

  • Image management functions

  • Full slideshow support

  • Rich list view (supports multiple sort orders)

  • File operations by drag and drop

  • Support for many thumbnail cache formats (all read and write)

    • GImageView (its own format, ~/.gimv/thumbnail)

    • Nautilus, Nautilus-2.0

    • Konqueror (also the old format)

    • GQview

    • Electric Eyes (Picview)

    • .xvpics

    The freedesktop.org Thumbnail Managing Standard (~/.cache/thumbnails) is not supported.

  • Supported image formats

    • JPEG, PNG, BMP, PCX, TGA, MAG, XBM, XCF, xvpics (gimv's own loaders)

    • PNM (PBM, PGM, PPM), XPM, Sun raster, WBMP (gimv's own loaders; added in the GTK 4 version)

    • SVG (librsvg), MNG (libmng), WMF (libwmf)

    • Formats that gdk-pixbuf can read, such as GIF, TIFF and ICO

    • WebP, AVIF, HEIF, JPEG XL, etc. (when the corresponding gdk-pixbuf loaders are installed)

    • Animated GIF, MNG

    Files in formats for which no loader is available are not shown in the thumbnail list. The supported formats can be checked in "Plugin Info" in [Help | About].

  • Supported archive formats

    • LZH

    • ZIP (CBZ)

    • TAR (tar.gz, tar.bz2, tar.xz, tar.zst, etc.)

    • RAR (CBR)

    • 7z (CB7)

    Archives are expanded as virtual directories. In the GTK 4 version, archives are read with libarchive (external commands such as lha and unzip are not used).

  • Supported movie formats

    • MPEG, AVI, QuickTime, WMV/ASF, MP4, Matroska (mkv), WebM, FLV, Ogg, MPEG-TS, 3GP, etc.

    • MP3, WAV, Ogg, FLAC, AAC, etc. (audio)

    Playing movies and audio requires one of GStreamer, MPlayer or xine-lib. The formats that can actually be played depend on what each of them supports. For GStreamer, this depends on the installed plugins (gstreamer1.0-plugins-good, -bad, -ugly, gstreamer1.0-libav, etc.).

1.3. System Requirements

The following are required to compile and run this program.

  • GTK 4.10 or later : https://www.gtk.org/

  • GLib 2.72 or later, gdk-pixbuf 2.0

  • Meson and Ninja (build time only)

  • X Window System (X11) (the environment it has been tested on). On Wayland, embedded movie playback with the MPlayer and xine plugins is not possible.

In addition, the following libraries and programs, if present, extend the functionality.

  • libarchive : Archives (zip, rar, 7z, lha, tar, etc.) can be opened.

  • libjpeg : JPEG images are loaded faster.

  • libexif : EXIF information can be displayed, and images can be rotated automatically according to the EXIF orientation information.

  • librsvg : SVG images can be displayed.

  • libmng : MNG animations can be played.

  • libwmf : WMF images can be displayed.

  • GStreamer 1.16 or later, xine-lib 1.2 or later, or MPlayer : Movie and audio files can be played.

  • Additional gdk-pixbuf loaders (webp-pixbuf-loader, libavif-gdk-pixbuf, heif-gdk-pixbuf, libjxl-gdk-pixbuf, etc.) : WebP, AVIF, HEIF, JPEG XL, etc. can be displayed.

The GTK 4 version has been tested on Debian (sid, GTK 4.24).

1.4. Getting GImageView

The original GImageView (up to 0.2.27) was published at the following location. It is no longer updated.

  • https://github.com/ashie/gimageview

The GTK 4 version is a port based on 0.2.27.

1.5. Installation

The GTK 4 version is built with Meson. In the top directory of the source, do the following. 

$ meson setup _build --prefix=/usr/local
$ ninja -C _build
$ sudo ninja -C _build install

Each feature is enabled automatically if the library is present. To specify them explicitly, add options like the following to meson setup. See meson_options.txt for the list of options. 

$ meson setup _build -Dgstreamer=enabled -Dxine=enabled -Dsvg=enabled -Dexif=enabled -Dmplayer=true

On Debian, you can also build a package and install it. 

$ dpkg-buildpackage -us -uc -b
$ sudo apt install ../gimageview_*.deb

The configuration files (~/.gimv) of the GTK+ 2 version can be used as they are. However, ~/.gimv/gtkrc is no longer used; instead, the appearance is changed with ~/.gimv/gtk.css.
