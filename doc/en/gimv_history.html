10. GImageView History

2026-09-26: Version 0.2.27+gtk4 (GTK 4 version)
    o Ported to GTK 4, built with Meson
    o Removed the support for Susie plugins
    o Removed lib/dllloader
    o The system libexif and GLib replace the bundled libexif and MD5 code
    o New loaders for PNM, XPM, Sun raster and WBMP
    o Formats of the installed gdk-pixbuf loaders (WebP, AVIF, HEIF, JPEG XL,
      ...) are recognized, and formats nothing can read are not listed
    o Supports new movie formats (mp4, mkv, webm, flv, etc.)
    o The scrollbars of the image view are shown only when the image does
      not fit
    o Added "Show splash window" to the preferences
    o "Plugin Info" in Help is split by type and shows descriptions and
      extensions
    o Converted the help documents to UTF-8; the built-in text viewer
      detects the character encoding automatically
    o Changed the default web browser to xdg-open
    o Comments on the thumbnail view ("Subject" and "Comment" columns in
      the detail view, a tooltip in the album view)
    o Comment editor window: Close button (Esc also closes it)

2002-11-04: Version 0.2.7
    o Fixed a problem where, in file operations, cache files and comment
      files were moved/copied/linked even when the file operation was
      cancelled or failed
    o Changed back to deleting the original file when moving a file to a
      different file system
	 o Fixed a problem where key accelerators were not disabled in the file
      name entry in rename mode (when using Gtk+2)
    o Fixed a problem where character encodings were not converted correctly
      in rename mode (when using Gtk+2)
    o Fixed a problem where moving the focus between thumbnails did not work
      correctly in the thumbnail view (when using Gtk+2)

2002-11-02: Version 0.2.6
    o Improved Gtk+-2.0 support (mainly support for GtkTreeView, and many
      other bug fixes)
    o Added a new sort menu
    o Fixed a problem where recursive loading with directories shown in the
      thumbnail view caused an infinite loop
    o Added a "Clear cache" menu to the thumbnail window
    o Fixed a problem where the ZAlbum widget did not take multibyte strings
      into account.
    o Fixed a problem where the character encoding conversion of file names
      in comment data was wrong.
    o Code cleanup
    o Other minor fixes

2002-09-22: Version 0.2.5
    o Improved the speed of creating thumbnails
    o Changed the default thumbnail display mode to "Thumbnail 2"
    o Directories whose thumbnails have been loaded are now highlighted
    o The image size can now be shown in "Detail" mode
    o Added mouse button settings for the directory view
    o The background color of the image window can now be set
    o Fixed compile errors (Thanks! Mr. Shitamori & Mr. Ezura)
    o Other minor fixes

2002-09-02: Version 0.2.4
    o Changed the behavior of "Fullscreen"
    o Changed the installation directory of the documents
    o Fixed configure/compile errors
    o Supports Nautilus-2.0 thumbnails
    o Improved compatibility of XV thumbnails with other programs
    o Improved Gtk+-2.0 support
    o Many other bug fixes

2002-07-01: Version 0.2.3
    o Added support for animated GIF (when using gdk-pixbuf)
    o Added MNG/JNG support (requires libmng)
    o Experimental support for compressed files (gzip, bz2). To use this
      feature, add "gz" and "bz2" to Preferences->Common->Filtering
    o Added a French catalog file (Thanks! Guillaume Libersat)
    o When loading thumbnails, thumbnails inside the visible area are now
      loaded first
    o Other bug fixes

2002-05-31: Version 0.2.2
    o Added SVG support (requires librsvg)
    o Added experimental movie file support (requires xine-lib)
    o Added experimental Susie plugin support (Broken)

    o Other minor improvements

2002-05-08: Version 0.2.1
    o In "Thumbnail 2" mode, improved the response when selecting a range by
      mouse drag, and made it accelerate according to the amount of mouse
      movement
    o Added "List 2" mode (uses the same ZAlbum widget as "Thumbnail 2")
    o ${datadir}/gimageview/gtkrc is now read
    o The style of the tab label is now changed while loading
    o Fixed a crash when closing an image window right after opening it
    o Fixed a crash when closing the similar image search result window after

    o Fixed a typo in the spec file, pointed out by ns

    o Supports XCF
    o The window composition can now be changed almost freely
    o The preferences window now has a tree structure
    o A splash image is now shown at startup
    o Brought back the scrollbars of the image view / added the navigation

    o Added "Thumbnail 2" mode
    o Added the similar image search feature

    o Provisional support for archive files
