8. GImageView FAQ

8.1. Getting, Installing and Starting

There is no configure

The GTK 4 version is built with Meson, not with configure (autoconf / automake). For the procedure, see Installation.

I want to start the GImageView thumbnail window alone
$ gimv -w

Start it like this. If [Edit | Options] - [Common | Startup | Open thumbnail window] is checked, the -w argument is not needed. 

$ gimv

alone starts it. After that, it works normally when you open some directory or file.

When registering it in a launcher, specifying just gimv is OK.

8.2. Operation and Settings

I want to change the defined key bindings

Edit ~/.gimv/keyconf. It takes effect from the next start. However, the key bindings shown in the menus do not change.

Menu shortcut keys can be changed in ~/.gimv/keyaccelrc. A line for every menu item is written out on exit, so remove the ";" at the beginning of the line you want to change and rewrite the key. For example, to make [File | Open] (Ctrl + F by default) of the thumbnail window F3, do the following. It takes effect from the next start. 

(gtk_accel_path "<ThumbWinMainMenu>/File/Open..." "F3")

Changing a shortcut by pressing a key while the mouse is over a menu item, which was possible in the GTK+ 2 version, is not possible in the GTK 4 version.

If you change the key bindings, only you know how it will behave. Please do this at your own risk.

8.3. Thumbnail Window

What does "**/** files" shown in the status bar mean?

It is the total number of files open in GImageView and the number of images in the displayed tab. It is also how many image files there are under that directory.

What does "**/** kB" shown in the status bar mean?

It is the total size of the files open in GImageView and the total size of the images in the displayed tab. It lets you know how much disk space the files directly under that directory use.

What does "**/** page" shown in the status bar mean?

It is the total number of tabs open in GImageView and the number of the currently displayed tab. You can see how many tabs are open now and which tab is the open one.

The deeper the hierarchy of the opened directory, the more characters a tab has. Depending on the hierarchy, it can happen that "only one tab can be shown on the screen". In such a case, you can grasp the whole picture from the numbers in the status bar. The numbers are 1 for the leftmost tab, followed by 2, 3, 4... When you close a tab, the numbers increase or decrease automatically.

How do I use the input entry on the right of the toolbar?

Try specifying various absolute paths. The directory tree (if you are showing it...) should do something interesting.

It is very hard to explain, but this is where you specify a new (or existing) tab in a command-line-like way. Even when the directory view is not shown, you can open a new tab or move to an existing tab without relying on the file open dialog.

In this input entry, completion with the TAB key works. Press TAB freely, as you would in bash, tcsh or zsh. If there is only one candidate, it is completed automatically. If there are many candidates, they are listed below the input entry. In this input entry, the shorthand "~/" for the user's home directory is ignored. Always specify an absolute path.

Also, individual files cannot be specified here. Input completion does not work for them either. If you want to open a single image in a separate window, first show that directory as thumbnails, and open it from there by middle-button click, left double-click or similar.

When the focus has moved to the input entry, use one of the following methods to move the focus back (to enable keyboard shortcuts).

  1. In the directory view, left-click some directory to "select" it.

  2. In the thumbnail view, click (select / unselect) some image.

  3. Click a tab to move to another tab.

  4. Left-click (or Shift + left-click) in the preview window to change the display.

  5. Press the Esc key.

Moving the focus from GImageView to another window (for example rxvt) does not switch the focus within GImageView. Note that the focus does not leave the input entry unless you do one of the operations described above.

8.4. Tabs

How do I show a list of the currently open tabs?

Right-click on the tab area. A list of the currently open tabs is shown. You can also move to any tab.

Stopping the full path display on tabs

Uncheck "Show full path" in [Preferences | Thumbnail Window | Tab]. Only the directory name will be shown on the tab. The full path of the open tab is then shown in the status bar, so check it there.

What is a collection tab?

You can make one from [File | New Collection]. Or select images in any tab and drag and drop them somewhere suitable.

The DnD menu appeared, right?

There, choose [Open in New Tab]. The dragged image (all of them, if there are several) is opened in a new tab (named Collection).

To add new images to a collection tab you made, there are the following methods.

  1. DnD onto the tab of the collection tab

  2. DnD onto the thumbnail view in the collection tab (in this case, from another application or from a second or later gimv)

  3. With the collection page open, select files from the file open dialog (the button at the left end of the toolbar), and use "Thumbnails of the selected files"

For DnD onto a collection page, the DnD menu is not shown and the files are added immediately.

After collecting, move or copy them to any directory. The collected images are treated as one group. Rather than Ctrl-clicking the images one by one, gathering them in a collection tab first and then doing file operations on them should make organizing images more efficient.

8.5. Directory View

How to show in the tree a directory added from the console

Do [Refresh Tree] on the parent directory of the added directory in the tree view, and it is shown. If you use [Make Directory...] from the right-click menu of the tree view, it is shown immediately, so adding directories this way is easier.

About "Load Thumbnails Recursively" in the right-click menu of the directory view

Loads everything under that directory recursively.

That is, it expands everything under that directory and makes a thumbnail tab for each directory. It is very convenient when you want to expand only a certain place. The tree is also expanded properly.

If you load recursively from a high-level directory (such as directly under ~/) and the directory loading does not stop, stop it with the stop button in the toolbar, or skip that directory with the skip button. If "GUI redraw interval while loading" in the preferences is set to a large value, the response is poor.

What are "." and ".." in the directory view?

Here is an example. 

/home/~
    + cg
       + .
       + ..
       + desktop
       + favorite
       |    + .   (1)
       |    + ..  (2)
       |    + web
       |    + download
       + tmp

Suppose it looks like this. If you double-click "." at (1), 

/home/~
   + web
   + download

that directory becomes the root directory. This means the same as [Go Here] in the right-click menu of the directory view.

And if you double-click ".." at (2), 

/home/~
   + desktop
   + favorite
   |    + web
   |    + dl
   + tmp

its parent directory becomes the root.

How to make the tree expand automatically and the view scroll up and down automatically during DnD from a tab window to the directory view

These settings ([Auto scroll] and [Enable auto expand directory tree]) exist only in the GTK+ 1.2 version, and not in the GTK+ 2 version and later (including the GTK 4 version). If the destination directory is collapsed, expand it beforehand.

8.6. Thumbnail View

Fixing the list view mode at startup and for new tabs

You can specify it in [Preferences | Thumbnail Window | Thumbnail View | Default display mode]. However, for this to take effect, "Save window state on exit" must be unchecked (not saved).

The thumbnails look strangely bad

A thumbnail cache of a different size may have been loaded. For now, run Update Thumbnail.

Selecting / unselecting all images at once

It is in the [Edit] menu. It is not in the mouse menu. Shortcuts are assigned (Ctrl + A [N]), so if you use it often, it is better to use those.

Clicking (toggling) a thumbnail does not change its color

The color of a selection depends on the current gtk theme. The color probably does not change because of the color settings of the theme. Try another theme.

8.7. Image View

About external commands

Leaves the display of images in a separate window to another program.

Set the external programs in [Preferences | External Program]. You can also register your own scripts and so on.
