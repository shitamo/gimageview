7. Default Key Bindings

7.1. Common

  • B : Tab ON/OFF

  • F : Maximize

  • M : Menubar ON/OFF

  • N : Toolbar ON/OFF

  • V : Statusbar ON/OFF

  • Ctrl + C : Quit GImageView entirely

  • Ctrl + F : File open dialog

  • Ctrl + I : New Image Window

  • Ctrl + O : Options

  • Ctrl + P : Print

  • Ctrl + Q : Close Window

  • Ctrl + T : New Tab

  • Ctrl + W : New Window

  • Shift + S : Scrollbar ON/OFF

  • Shift + F10 : Popup menu

7.2. Thumbnail Window

  • H : Previous Page (tab)

  • J : Last Page (tab)

  • K : First Page (tab)

  • L : Next Page (tab)

  • Q : Close Tab

  • Shift + Ctrl + R : Refresh List

  • Alt + 1-6 : Display mode of the thumbnail view (Album, Album2, Album3, Detail, Detail + Icon, Detail + Thumbnail)

  • Ctrl + 0 : Layout 0

  • Ctrl + 1 : Layout 1

  • Ctrl + 2 : Layout 2

  • Ctrl + 3 : Layout 3

  • Ctrl + 4 : Layout 4

  • Ctrl + A : Select All

  • Ctrl + D : Detach Tab

  • Ctrl + N : Unselect All

  • Ctrl + Q : Close Window

  • Ctrl + R : Update All Thumbnails

  • Ctrl + S : Slideshow

  • Ctrl + T : New Tab

  • Shift + C : Copy Files To...

  • Shift + B : Move Tab Backward

  • Shift + D : Directory View ON/OFF

  • Shift + E : Rename...

  • Shift + F : Move Tab Forward

  • Shift + L : Link Files To...

  • Shift + M : Move Files To...

  • Shift + N : DirView Toolbar ON/OFF

  • Shift + P : Preview ON/OFF

  • Shift + R : Reload Cache

  • Shift + Z : Tab (Preview) ON/OFF

7.3. Thumbnail Window / Thumbnail View

  • Cursor keys : Move the cursor

  • Space : Select/unselect the file

  • Enter : Select only that file and open the image

  • Shift + Enter : Select that file and open the image

  • Delete : Remove the selected files

However, the file selection behavior may differ slightly depending on the mode.

7.6. Mouse

7.6.1. Thumbnail View

  • Button 1 (left click) : Open (Auto select window)

  • Ctrl + Button 1 (Ctrl + left click) : none

  • Shift + Button 1 (Shift + left click) : Selects everything up to the clicked image at once. It cannot unselect. Use Unselect All (Ctrl+N).

  • Alt + Button 1 (Alt + left click) : none

  • Button 2 (middle click) : Open (Auto & Force)

  • Ctrl + Button 2 (Ctrl + middle click) : none

  • Shift + Button 2 (Shift + middle click) : none

  • Alt + Button 2 (Alt + middle click) : none

  • Button 3 (right click) : Popup menu

  • Ctrl + Button 3 (Ctrl + right click) : none

  • Shift + Button 3 (Shift + right click) : none

  • Alt + Button 3 (Alt + right click) : none

  • Button 1 double click (left double click) : Open (Auto & Force)

  • Ctrl + Button 1 double click (Ctrl + left double click) : none

  • Shift + Button 1 double click (Shift + left double click) : none

  • Alt + Button 1 double click (Alt + left double click) : none

  • Button 4 (wheel up) : none

  • Ctrl + Button 4 (Ctrl + wheel up) : none

  • Shift + Button 4 (Shift + wheel up) : none

  • Alt + Button 4 (Alt + wheel up) : none

  • Button 5 (wheel down) : none

  • Ctrl + Button 5 (Ctrl + wheel down) : none

  • Shift + Button 5 (Shift + wheel down) : none

  • Alt + Button 5 (Alt + wheel down) : none

  • Button 8 (side button "back") : none

  • Button 9 (side button "forward") : none
