1. はじめに

1.1. これは何?

GImageView は超大量画像(動画)表示下における絶望的状況を打破すべく開発中の、XWindowSystem 上で動作する画像閲覧ソフトです。

この版 (0.2.27+gtk4) は、GImageView 0.2.27 を GTK 4 に移植したものです。X Window System (X11) の上で動作を確認しています。Wayland では MPlayer・xine プラグインによる動画の埋め込み再生はできません。

基本的に、画像閲覧ソフトですが、バージョン 0.1.1 以降、ドラッグ&ドロップによる簡単なファイル操作(画像管理機能)も実装しています。0.2.3 からは xine や MPlayer を利用した動画の再生機能にも対応しています (GTK 4 版では GStreamer にも対応しました)。なお、0.2.3 で実験的に対応した susie プラグインは、GTK 4 版では削除しました。

1.2. 特徴

GImageView は、以下のような特徴を持っています。

  • 複数ディレクトリの同時オープン、タブによるサムネイルビュー切り替え

  • 任意ディレクトリの再帰的読み込み・ルート設定可能

  • 低消費メモリ

  • コマンドラインからの使用を充分に考慮

  • シンプルかつ柔軟なインターフェース

  • 画像管理機能

  • スライドショー完備

  • 充実したリストビュー(複数の並び換えに対応)

  • ドラッグ&ドロップによるファイル操作

  • 多数のサムネイルキャッシュ形式に対応 (いずれも読み書き対応)

    • GImageView (独自の形式。~/.gimv/thumbnail)

    • Nautilus、Nautilus-2.0

    • Konqueror (旧形式を含む)

    • GQview

    • Electric Eyes (Picview)

    • .xvpics

    freedesktop.org の Thumbnail Managing Standard (~/.cache/thumbnails) には対応していません。

  • 対応画像形式

    • JPEG、PNG、BMP、PCX、TGA、MAG、XBM、XCF、xvpics (gimv独自のローダ)

    • PNM (PBM・PGM・PPM)、XPM、Sun raster、WBMP (gimv独自のローダ。GTK 4 版で追加)

    • SVG (librsvg)、MNG (libmng)、WMF (libwmf)

    • GIF、TIFF、ICO など、gdk-pixbuf が読める形式

    • WebP、AVIF、HEIF、JPEG XL など (対応する gdk-pixbuf の読み込み部品がインストールされている場合)

    • アニメーションGIF、MNG

    読み込める処理がない形式のファイルは、サムネイル一覧に表示しません。対応している形式は、[ヘルプ | GImageView について] の「プラグイン情報」で確認できます。

  • 対応書庫(アーカイブ)形式

    • LZH

    • ZIP (CBZ)

    • TAR (tar.gz、tar.bz2、tar.xz、tar.zst など)

    • RAR (CBR)

    • 7z (CB7)

    書庫は、仮想ディレクトリとして展開されます。GTK 4 版では、書庫は libarchive で読み込みます (lha や unzip などの外部コマンドは使いません)。

  • 対応動画形式

    • MPEG、AVI、QuickTime、WMV・ASF、MP4、Matroska (mkv)、WebM、FLV、Ogg、MPEG-TS、3GP など

    • MP3、WAV、Ogg、FLAC、AAC など (音声)

    動画・音声の再生には GStreamer、MPlayer、xine-lib のいずれかが必要です。実際に再生できる形式は、それぞれの側の対応によります。GStreamer の場合は、インストールされているプラグイン (gstreamer1.0-plugins-good、-bad、-ugly、gstreamer1.0-libav など) によります。

1.3. 動作環境

このプログラムのコンパイル及び実行には、以下のものが必要です。

  • GTK 4.10 以降 : https://www.gtk.org/

  • GLib 2.72 以降、gdk-pixbuf 2.0

  • Meson と Ninja (ビルド時のみ)

  • X Window System (X11) (動作を確認している環境)。Wayland では MPlayer・xine プラグインによる動画の埋め込み再生はできません。

また、下記のライブラリ・プログラムがある場合、機能を拡張することができます。

  • libarchive : 書庫 (zip、rar、7z、lha、tar など) を開く事ができます。

  • libjpeg : JPEG を高速に読み込みます。

  • libexif : EXIF 情報の表示と、EXIF の向き情報による自動回転ができます。

  • librsvg : SVG を表示する事ができます。

  • libmng : MNG を再生する事ができます。

  • libwmf : WMF を表示する事ができます。

  • GStreamer 1.16 以降、xine-lib 1.2 以降、または MPlayer : 動画・音声ファイルを再生する事ができます。

  • gdk-pixbuf の追加の読み込み部品 (webp-pixbuf-loader、libavif-gdk-pixbuf、heif-gdk-pixbuf、libjxl-gdk-pixbuf など) : WebP、AVIF、HEIF、JPEG XL などを表示する事ができます。

GTK 4 版は Debian (sid, GTK 4.24) で動作を確認しています。

1.4. 入手方法

元の GImageView (0.2.27 まで) は、以下で公開されていました。現在は更新されていません。

  • https://github.com/ashie/gimageview

GTK 4 版は、0.2.27 を元に移植したものです。

1.5. インストール

GTK 4 版は Meson でビルドします。ソースのトップディレクトリで、以下のようにします。 

$ meson setup _build --prefix=/usr/local
$ ninja -C _build
$ sudo ninja -C _build install

各種機能は、ライブラリがあれば自動的に有効になります。明示的に指定する場合は、meson setup に以下のようなオプションを付けて下さい。オプションの一覧は meson_options.txt を見て下さい。 

$ meson setup _build -Dgstreamer=enabled -Dxine=enabled -Dsvg=enabled -Dexif=enabled -Dmplayer=true

Debian では、パッケージを作ってインストールすることもできます。 

$ dpkg-buildpackage -us -uc -b
$ sudo apt install ../gimageview_*.deb

設定ファイル (~/.gimv) は GTK+ 2 版のものをそのまま使えます。ただし、~/.gimv/gtkrc は使われなくなり、代わりに ~/.gimv/gtk.css で見た目を変更します。
