1. はじめに
===========

1.1. これは何?

GImageView は超大量画像(動画)表示下における絶望的状況を打破すべく開発中の、
XWindowSystem 上で動作する画像閲覧ソフトです。

この版 (0.2.27+gtk4) は、GImageView 0.2.27 を GTK 4 に移植したものです。X
Window System (X11) の上で動作を確認しています。Wayland では MPlayer・xine プ
ラグインによる動画の埋め込み再生はできません。

基本的に、画像閲覧ソフトですが、バージョン 0.1.1 以降、ドラッグ&ドロップによる
簡単なファイル操作(画像管理機能)も実装しています。0.2.3 からは xine や MPlayer
を利用した動画の再生機能にも対応しています (GTK 4 版では GStreamer にも対応し
ました)。なお、0.2.3 で実験的に対応した susie プラグインは、GTK 4 版では削除し
ました。

1.2. 特徴

GImageView は、以下のような特徴を持っています。

 ・ 複数ディレクトリの同時オープン、タブによるサムネイルビュー切り替え

 ・ 任意ディレクトリの再帰的読み込み・ルート設定可能

 ・ 低消費メモリ

 ・ コマンドラインからの使用を充分に考慮

 ・ シンプルかつ柔軟なインターフェース

 ・ 画像管理機能

 ・ スライドショー完備

 ・ 充実したリストビュー(複数の並び換えに対応)

 ・ 画像の索引: 撮影日・タグ・自動タグ (フォルダ名、カメラ、形) で画像を探す、
    複数の条件での検索と検索の保存 (2.6、2.8)

 ・ 顔の認識: 写っている人で画像を探す、顔に名前を付ける (2.7)

 ・ ドラッグ&ドロップによるファイル操作

 ・ 多数のサムネイルキャッシュ形式に対応 (いずれも読み書き対応)

     □ freedesktop.org の Thumbnail Managing Standard (~/.cache/thumbnails。他
       のプログラムと共有)

     □ GImageView (独自の形式。~/.gimv/thumbnail)

     □ Nautilus、Nautilus-2.0

     □ Konqueror (旧形式を含む)

     □ GQview

     □ Electric Eyes (Picview)

     □ .xvpics

 ・ 対応画像形式

     □ JPEG、PNG、BMP、PCX、TGA、MAG、XBM、XCF、xvpics (gimv独自のローダ)

     □ PNM (PBM・PGM・PPM)、XPM、Sun raster、WBMP、ZIM、Pi、PIC、PIC2、MAKI
       (.mki)、MB (PC-8801)、MB2 (PC-9801)、AK5/MSL (gimv独自のローダ。GTK 4
       版で追加。MAG・ZIM・Pi・PIC・PIC2・MAKI・MB・MB2 は実機の画面での画素の
       形で表示します: PC-9801 などは縦 1.2 倍、X68000 の 512 ドット幅の画面は
       横 4/3 倍、MAG と MB2 の 200 ライン モードと MB はさらに縦 2 倍。画像サ
       イズも伸ばした後の大きさです)

     □ SVG (librsvg)、MNG (libmng)、WMF (libwmf)

     □ GIF、TIFF、ICO など、gdk-pixbuf が読める形式

     □ WebP、AVIF、HEIF、JPEG XL など (対応する gdk-pixbuf の読み込み部品がイ
       ンストールされている場合)

     □ アニメーションGIF、MNG

    読み込める処理がない形式のファイルは、サムネイル一覧に表示しません。対応し
    ている形式は、[ヘルプ | GImageView について] の「プラグイン情報」で確認で
    きます。

 ・ 対応書庫(アーカイブ)形式

     □ LZH (liblhasa があれば、古い圧縮方式 (-lh1-・-lh4-・-lzs-・-lz5-・-pm1-
       など) と自己解凍形式 (MS-DOS・X68000 など) も。なければ LHarc 1.x の
       -lh1- も)

     □ ZIP (CBZ)

     □ TAR (tar.gz、tar.bz2、tar.xz、tar.zst など)

     □ RAR (CBR)

     □ 7z (CB7)

    書庫は、仮想ディレクトリとして展開されます。GTK 4 版では、書庫は
    libarchive で読み込みます (lha や unzip などの外部コマンドは使いません)。

 ・ 対応動画形式

     □ MPEG、AVI、QuickTime、WMV・ASF、MP4、Matroska (mkv)、WebM、FLV、Ogg、
       MPEG-TS、3GP など

     □ MP3、WAV、Ogg、FLAC、AAC など (音声)

    動画・音声の再生には GStreamer、MPlayer、xine-lib のいずれかが必要です。実
    際に再生できる形式は、それぞれの側の対応によります。GStreamer の場合は、イ
    ンストールされているプラグイン (gstreamer1.0-plugins-good、-bad、-ugly、
    gstreamer1.0-libav など) によります。

1.3. 動作環境

このプログラムのコンパイル及び実行には、以下のものが必要です。

 ・ GTK 4.12 以降 : https://www.gtk.org/

 ・ GLib 2.72 以降、gdk-pixbuf 2.0

 ・ Meson と Ninja (ビルド時のみ)

 ・ X Window System (X11) (動作を確認している環境)。Wayland では MPlayer・xine
    プラグインによる動画の埋め込み再生はできません。

また、下記のライブラリ・プログラムがある場合、機能を拡張することができます。

 ・ libarchive : 書庫 (zip、rar、7z、lha、tar など) を開く事ができます。

 ・ liblhasa : 古い LHA (lzh) の書庫をすべての圧縮方式で読み、自己解凍形式の書
    庫も開けます (libarchive と一緒に使います)。

 ・ libjpeg : JPEG を高速に読み込みます。

 ・ libexif : EXIF 情報の表示と、EXIF の向き情報による自動回転 (サムネイルも)
    ができます。JPEG の縮小画像 (EXIF) でサムネイルを速く作れます。

 ・ gexiv2 (Exiv2) : libexif と合わせて、JPEG 以外 (TIFF・RAW・PNG・WebP・
    HEIF/AVIF・JPEG XL など) の EXIF も表示・自動回転に使えます。索引は撮影日
    時・カメラ・キーワード (EXIF・XMP・IPTC) をこれらの形式からも読みます。

 ・ SQLite 3.22 以降 : 画像の索引 (日付・タグ・検索) が使えます。

 ・ OpenCV 4.8 以降 (C++ コンパイラも必要) : 索引で顔を認識できます。別にモデ
    ルファイル (OpenCV の YuNet と SFace) が必要です。

 ・ librsvg (2.52 以降) : SVG を表示する事ができます。

 ・ libmng : MNG を再生する事ができます。

 ・ libwmf : WMF を表示する事ができます。

 ・ GStreamer 1.16 以降、xine-lib 1.2 以降、または MPlayer : 動画・音声ファイ
    ルを再生する事ができます。

 ・ gdk-pixbuf の追加の読み込み部品 (webp-pixbuf-loader、libavif-gdk-pixbuf、
    heif-gdk-pixbuf、libjxl-gdk-pixbuf など) : WebP、AVIF、HEIF、JPEG XL など
    を表示する事ができます。

GTK 4 版は Debian (sid, GTK 4.24) で動作を確認しています。

1.4. 入手方法

元の GImageView (0.2.27 まで) は、以下で公開されていました。現在は更新されてい
ません。

 ・ https://github.com/ashie/gimageview

GTK 4 版は、0.2.27 を元に移植したものです。

1.5. インストール

GTK 4 版は Meson でビルドします。ソースのトップディレクトリで、以下のようにし
ます。

  $ meson setup _build --prefix=/usr/local
  $ ninja -C _build
  $ sudo ninja -C _build install

各種機能は、ライブラリがあれば自動的に有効になります。明示的に指定する場合は、
meson setup に以下のようなオプションを付けて下さい。オプションの一覧は
meson_options.txt を見て下さい。

  $ meson setup _build -Dgstreamer=enabled -Dxine=enabled -Dsvg=enabled -Dexif=enabled -Dmplayer=true

Debian では、パッケージを作ってインストールすることもできます。

  $ dpkg-buildpackage -us -uc -b
  $ sudo apt install ../gimageview_*.deb

設定ファイル (~/.gimv) は GTK+ 2 版のものをそのまま使えます。ただし、~/.gimv/
gtkrc は使われなくなり、代わりに ~/.gimv/gtk.css で見た目を変更します。

2. 使い方
=========

2.1. コマンドライン

以下の様にコマンドを打つと、画像ファイルを見ることが出来ます。

  $ gimv [画像ファイル名...]

また、以下の様に "-d" オプションを付けてディレクトリ名を指定すると、サムネイル
ウィンドウに、ディレクトリの全ての画像ファイルをサムネイルで開きます。

  $ gimv -d [ディレクトリ名]

以下のような感じで画像ファイル名とディレクトリ名を入り乱れて指定すると、画像ファ
イルはイメージウィンドウで、ディレクトリはサムネイルウィンドウで開きます。

  $ gimv -d hoge01.jpg ~/ ~/images images/hoge02.jpg\
    /usr/share/pixmaps/ hogehoge.png ......

"-t" オプションを付けて、全てをサムネイルウィンドウで開く事もできます。

その他コマンドラインオプションの詳細は以下のとおりです。

  $ gimv -h

  Copyright (C) 2001 Takuro Ashie
  Usage: gimv [オプション...] [画像ファイル名...]

    -d, --directory          ディレクトリを読み込む
    -R, --recursive          ディレクトリを再帰的に取得("-d"と共に使用)
    -D, --scan-dot           ディレクトリ走査時にドットファイルも読み込む
    -e, --ignore-ext         拡張子を無視する
    -s, --scale=SCALE        イメージビューでの画像拡大率を指定(%)
    -b, --buffer=ON/OFF      元の画像をメモリに保持するか否か
    -M, --menubar            イメージビューにメニューバーを表示
    -T, --toolbar            イメージビューにツールバーを表示
    -I, --imagewin           空のイメージウィンドウを開く
    -w, --thumbwin           サムネイルウィンドウを開く
    -i, --imageview          全ての画像をイメージビューで開く
    -t, --thumbview          全ての画像をサムネイルビューで開く
    -S, --slideshow          画像をスライドショーで開く
    -W, --wait=TIME          スライドショーの画像切替え間隔 ("-S"と共に使用) [sec]
    -v, --version            バージョン情報を表示
    -h, --help               このメッセージを表示

GUI からディレクトリを開きたい場合は、ディレクトリビューで該当するディレクトリ
をダブルクリックするか、サムネイルウィンドウのツールバーのディレクトリ入力欄に
パスを入力して Enter を押して下さい (画像のあるディレクトリだけが、新しいタブ
で開きます)。ファイルオープンダイアログでディレクトリを選んで「選択したファイ
ルのサムネイル」を押しても開けます。

2.2. サムネイル

 ・ サムネイルは freedesktop.org の Thumbnail Managing Standard の形式 (~/
    .cache/thumbnails) で読み書きでき、他のプログラムと共有できます ([設定 |
    サムネイルキャッシュ])。

 ・ JPEG・PNG など GdkPixbuf で読める画像のサムネイルは別スレッドで作るので、
    作成中も操作できます。JPEG に十分な大きさの縮小画像 (EXIF) があればそれを
    使います ([設定 | サムネイルキャッシュ] の「サムネイルの作成」)。

 ・ サムネイルは EXIF の向き (回転・左右反転) どおりに表示し、その向きでキャッ
    シュに保存します。イメージビューで回転・左右反転して記憶した向きがあれば、
    その向きで表示します (キャッシュには保存しません)。

2.3. 一覧の操作

一覧の検索 (Ctrl+F)
    ディレクトリビュー、詳細表示、データタブ、設定の一覧などで Ctrl+F を押すと、
    一覧の上に検索欄が出ます。ファイル名・フォルダ名・タグ名など、一覧に出てい
    る名前を入力すると、その文字で始まるもの (なければ含むもの) を選びます。↑↓
    で前・次の一致に移り、Enter で決定、Esc で閉じます (5 秒入力しないと閉じま
    す)。索引のタブでは、畳んである中の名前も探します。サムネイルビューのアル
    バム表示でも、Ctrl+F でファイル名からサムネイルを探せます (見つけた画像を
    選んで見える位置まで送り、Enter で開きます)。サムネイルビュー以外にフォー
    カスがある時の Ctrl+F は [ファイル | 開く...] です。

ステータスバー
    左にフォーカスのある画像のフルパス、中央に「何枚目 / 全体の枚数」とファイ
    ルのサイズを表示します。複数の画像を選ぶと「n 枚選択」と選んだ画像の合計の
    サイズを表示します。右端は索引の状態とお知らせです。

2.4. コメント (データ・ノート・タグ)

GImageView は、画像ごとの題名・日付・場所などのメモやタグを、画像ファイルを書
き換えずに、別のテキストファイル (コメントファイル) に保存します。マニュアルで
「コメント」と書いているのはこのファイルの中身のことです。

コメントファイル
    画像 1 枚ごとに、~/.gimv/comment の下に、画像のフルパスに「.txt」を付けた
    名前で作ります (例: /home/user/Pictures/cat.jpg なら ~/.gimv/comment/home/
    user/Pictures/cat.jpg.txt)。中身は「キー: 値」の行 (データ) と、その後の自
    由な文章 (ノート) です。文字コードは [設定 | コメント] で指定します。コメ
    ントを付けていない画像にはファイルはありません。

保存されるもの
    「データ」タブで入れた値 (題名・日付・場所など。項目は [設定 | コメント]
    のキー定義で増やせます)、「ノート」タブの文章、「タグを編集...」で手動で付
    けたタグ (X-IMG-Tags の行)、顔に付けた名前 (「person/名前」のタグ)、画像ご
    との回転・左右反転の向き (コメントの編集画面には出ません) です。索引が自動
    で付けるタグや、画像ファイルの中のコメント・EXIF・キーワードは、コメントファ
    イルには書きません。

見る・編集する
    サムネイルの右クリックかイメージウィンドウの [編集 | コメントを編集...] で
    コメントウィンドウを開きます。プレビューの「データ」タブにも同じ内容が出ま
    す。詳細表示の「題名」「コメント」列、アルバム表示のツールチップにも表示で
    きます。

「データ」タブ
     ・ プレビューとコメントウィンドウの「データ」タブには、画像ファイル自体に
        書かれたコメント (JPEG・PNG・GIF・MAG・MAKI・Pi・PIC・PIC2・MB2・AK5/
        MSL) を斜体で表示します (表示のみ)。一覧には最初の 4 行と残りの行数が
        出ます (マウスを置くと全文がポップアップで出ます)。選ぶと、値の欄の代
        わりに全文を改行どおりに表示します。書庫の中の画像も、プレビューのため
        に取り出したファイルから読んで表示します。

     ・ 曲や動画では、ファイルに入っている情報 (タイトル・アーティスト・アルバ
        ム・トラック・ジャンル・長さ・音声や映像の形式など) も「データ」タブに
        斜体で表示します (表示のみ、GStreamer プラグイン)。

     ・ 「データ」タブでは、「キー」を選んで「値」を入れ、Enter か「保存」で登
        録します (値の書き方に決まりはありません。ただし「日付」に日付として読
        める値を書くと、索引はそれを撮影日にします)。

     ・ 「データ」タブの「項目を削除」(一覧では Delete キー) は選んでいる項目
        を消し、「保存」で確定します。下の「コメントを削除...」は、確認のあと、
        その画像のデータとノートを消します。タグ (X-IMG-Tags) は残ります。タグ
        の行は表示だけで、タグは「タグを編集...」で編集します。

画像の移動と索引
    GImageView で画像を移動・コピー・名前変更すると、コメントファイルも一緒に
    移ります。他のプログラムで移動して見つからなくなった画像は [ツール | 行方
    不明の画像...] で付け直せます。コメントファイルは索引のデータベースとは別
    なので、索引を作り直してもタグや名前は失われません。

2.5. ブックマーク

気になった画像に、後から見返すための印を付けられます。索引の対象外のフォルダの
画像にも付けられます。よく見るフォルダや書庫にも付けられます。ブックマークは
~/.gimv/bookmarks に保存します (索引のデータベースとは別なので、索引を作り直し
ても消えません)。

付け方
    サムネイルビューで画像を選び (複数可)、[編集 | ブックマーク...] か右クリッ
    クの「ブックマーク...」を選びます。イメージウィンドウでは [編集 | ブックマー
    ク...]、プレビューでは右クリックの「ブックマーク...」です。選んだ時点でブッ
    クマークが付き、メモの欄が出ます。メモは何も書かずに Esc で閉じてもかまい
    ません (雑に付けておいて、後から書けます)。Enter か欄の外をクリックすると、
    書いたメモを保存します。すでに付いている画像で選ぶと、メモを直したり「外す」
    で外したりできます。フォルダ・書庫も同じように選んで付けます (サムネイルビュ
    ーに出ているフォルダ・書庫か、ディレクトリのタブの右クリックの「ブックマー
    ク...」)。

キー
    標準ではキーは割り当てていません。[編集 | キーボードショートカット...] で
    割り当てられます。~/.gimv/keyaccelrc に次のように書いても、次の起動からそ
    のキーで付けられます (Ctrl+K の例。行の先頭に「;」があると無効です)。

      (gtk_accel_path "<ThumbWinMainMenu>/Edit/Bookmark..." "<Control>k")
      (gtk_accel_path "<ImageWinMainMenu>/Edit/Bookmark..." "<Control>k")
      (gtk_accel_path "<ThumbWinPreviewPop>/Bookmark..." "<Control>k")

ブックマークタブ
    ディレクトリビューの並びの「ブックマーク」タブ (星) に、付けた日ごと (今日、
    昨日、1 週間以内、それより前は月ごと) と、「全て」「メモあり」「メモなし」
    が件数付きで並びます。どれかをクリックすると、結果のタブに新しく付けたもの
    から順に開きます (索引のタブと同じく、ファイル名だけを表示)。並べ替えのメ
    ニューを選ぶと、その順になります。ブックマークしたフォルダ・書庫は「フォル
    ダ・書庫」の下に名前順に並び、クリックするとそのフォルダ・書庫を自分のタブ
    で開きます (月ごとや「全て」には入りません)。

メモの表示
    ブックマークを付けた画像 (フォルダ・書庫) は、アルバム表示 (サムネイル・ア
    イコン) では画像の右上の角に黄色い★が付きます。詳細表示では「ブックマーク」
    のコラム (見出しは★) に★が出ます (既定のコラムには入っていないので、[設定
    | サムネイルウィンドウ | サムネイルビュー | 詳細ビュー] で加えてください)。
    ブックマークしたフォルダは、ディレクトリのタブのツリーでもフォルダのアイコ
    ンの中央に★が付き、マウスを乗せるとメモが出ます。ブックマークを付けたり外
    したりすると、すぐに変わります。サムネイルのツールチップの先頭には「★ メモ」
    (メモがなければ「★ ブックマークされています」) を表示します。

移動と行方不明
    GImageView で名前を変えたり移動したりした画像は、ブックマークも一緒に移り
    ます。索引の対象のフォルダでは、GImageView の起動中にほかのプログラムで移
    動・名前変更した画像やフォルダにも付いていきます。

    それ以外 (GImageView を起動していない間の移動・名前の変更・削除、索引の対
    象外のフォルダ、つながっていないドライブ) で見つからなくなったものは、タブ
    の「見つからない (件数)」に出ます。クリックすると「見つからないブックマー
    ク」のウィンドウが開き、パス・付けた日時・メモ・移動先の候補が並びます。移
    動先の候補は、索引にある同じ名前のファイル (フォルダ) です。1 つだけならそ
    のパス、いくつもあれば件数を出します (マウスを乗せると全部)。

     ・ 移動先に付け直す : 候補が 1 つの行のブックマークを、メモ・付けた日時ご
        とその候補に移します (複数選べます)。

     ・ 別の場所に付け直す... : 付け直す先を選びます (最初の候補か、元のフォル
        ダから。拡張子のない名前はフォルダを選びます)。

     ・ ブックマークを外す : 消してしまったものなどのブックマークを外します。

    付け直す先にすでにブックマークがあれば、そちらを残します。つながっていない
    ドライブのものなどもあるので、自動では外しません。索引を使っていない時は、
    移動先の候補は探しません。

2.6. 画像の索引 (日付・タグ)

[設定 | 索引] で「索引を作るディレクトリ」を指定すると、GImageView の起動中に
索引プロセス (gimv-indexer) がその下の画像を調べ、撮影日時とタグのデータベース
(~/.local/share/gimageview/index.db) を作ります。索引プロセスは低い優先度で動
き、起動中のファイルの追加・移動・削除も取り込みます。進み具合はステータスバー
の右端に「索引: …」と表示されます。SQLite を使ってビルドした場合だけの機能です。

索引ができると、サムネイルウィンドウのディレクトリビューの欄に「日付」「タグ」
のタブが (顔が使える場合は「人物」も) 増えます。

日付タブ
    画像を撮影日で年・月・日に分け、枚数とともに新しい順に表示します。撮影日は、
    コメントの「日付」に書いた日付 (「2025-04-01」「2025/4/1 10:15」「2025年4
    月1日 10時15分」など。SNS の画像のように EXIF が消され、ファイル名も日付で
    ない画像に)、なければ EXIF (gexiv2 を使ってビルドした場合は XMP も) の撮影
    日時、なければファイル名に含まれる日付、それもなければ更新日時です。日付を
    クリックすると、結果のタブにその日 (月・年) の画像を撮影日の新しい順に開き
    ます。詳細表示では「撮影日」の見出しに▼が付きます。[表示 | ファイルソート]
    や詳細表示の見出しで選ぶと、その順になります (もう一度同じ項目を選んでも並
    べ直します)。

タグタブ
    手動で付けたタグを上に、その下に「人物名」と、自動で付いたタグのグループ
    (青色: フォルダ、カメラ、形、人物のタグ) を表示します。他のプログラムが付
    けたキーワードは、同じ名前の手動で付けたタグと 1 つにまとめて上の一覧に出
    します (クリックするとどちらかが付いた画像。改名・統合は手動で付けたタグだ
    けで、キーワードは付けたプログラムで直します)。

    タグは「/」で区切ると階層になります。「旅行/京都/寺」は「旅行」の下の「京
    都」の下に「寺」として表示します (他のプログラムの階層キーワードも同じです)
    。親の枚数は下のタグの画像を含めた枚数で、親をクリックすると下のタグの画像
    も全て開きます。親のタグは、画像に直接付けていなくても表示します。改名
    (F2) はタグの名前全体 (「旅行/京都」) を直し、親を改名すると下のタグも一緒
    に変わります (「旅行」を「旅」にすると「旅/京都」に)。名前の「/」の前を変
    えれば、別の親の下へ移せます。手動で付けたタグは、タグタブの中でドラッグし
    て別のタグの上で離すと、「「旅行」の下へ移動 (旅行/猫)」「「旅行」に統合」
    を選べます (下のタグも一緒に移ります)。「タグ」の行か一覧の下の空いている
    所で離すと、一番上へ移せます。統合するときや、移した先に同じ名前のタグがあ
    るときは確認します。自動タグ・キーワードだけのタグ・人物名は動かせません。
    検索ウィンドウでタグを指定した場合も、下のタグの画像を含みます。

開き方
    日付・タグ・人物などの名前をクリックすると、その画像をサムネイルビューの結
    果のタブに表示します (結果のタブは 1 つで、内容を入れ替えます)。名前の右の
    件数や空いた所をクリックしても同じです。▶ のクリックは下を開いたり閉じたり
    するだけで、画像は開きません。中ボタンのクリックか、右クリックの「新しいタ
    ブで開く」で新しいタブに開きます。矢印キーで行を移っただけでは開かず、
    Enter で開きます。結果のタブはファイル名だけを表示し、フルパスはツールチッ
    プとステータスバーに出ます。右クリックの「元のフォルダを開く」で、その画像
    のあるフォルダを開けます。数万枚の結果でも、見えている付近のサムネイルだけ
    を作ります。

タグを付ける
    サムネイルの右クリックか [編集 | タグを編集...] で、選んだ画像 (複数可) に
    タグを付けます。イメージウィンドウでは [編集 | タグを編集...] か画像の右ク
    リック、プレビューでは右クリックの「タグを編集...」で、表示している画像の
    タグを編集します。上の欄にタグを入力して Enter で付けます (カンマ区切りで
    複数、「旅行/京都」のように「/」を含めても構いません)。付いているタグは下
    に並び、× で外せます。一番下の「使われているタグ」はよく使われている順で、
    入力すると絞り込まれ、クリックで付けます。階層のあるタグは親の部分を薄い字
    で「旅行/京都」のように表示します。候補の行の親の部分 (「旅行」) をクリッ
    クすると入力欄が「旅行/」になり、候補が「旅行」の下のタグだけに絞られるの
    で、続けて子の名前を入力するか、候補から選びます。「/」を含めて入力したと
    きは、その文字で始まるタグだけを候補にします。複数の画像では、一部の画像に
    だけ付いているタグを「京都 2/5」のように表示し、クリックで全部に付け、× で
    全部から外します (そのままなら各画像のまま)。何も入力していないときの
    Enter で決定します。

    ディレクトリビューでフォルダを右クリックして「下のフォルダも含めてタグを編
    集...」を選ぶと、そのフォルダと下のフォルダにある画像すべてが対象になりま
    す (開いたり選んだりする必要はありません)。画像を探すのは裏で行い、時間が
    かかるときは見つかった枚数を表示します (キャンセルできます)。ダイアログの
    使い方は同じです。枚数が多いときは書き込みの進み具合を表示し、「中止」で止
    められます。止めたときは、それまでの画像だけが変わり、残りは元のままです。
    書き込む前にすべての画像を確認するので、タグが長すぎる画像があるときは何も
    書き込みません。

    タグはコメントファイル (~/.gimv/comment、2.4) の「X-IMG-Tags:」の行に書か
    れ、索引を作り直しても失われません。顔に付けた人物の名前 (「person/名前」
    のタグ) は欄には出さずに「人物」に表示し、タグの編集では変わりません (名前
    は顔の一覧ウィンドウか顔パネルで付けます)。コメントウィンドウとプレビュー
    の「データ」タブの「タグ:」の行には、その画像のタグが並び、クリックすると
    そのタグの画像を開きます。階層のあるタグは「旅行 / 京都 / 寺」のように部分
    ごとに並び、親の部分 (薄い字) をクリックすると、その親と下のタグの画像をま
    とめて開きます。

タグの名前の変更・統合
    タグタブで手動で付けたタグ (または人物のタグ) を選び、F2 か右クリックの
    「名前を変更...」で名前を変えます。同じ名前のタグがあれば、1 つにまとめる
    か確認します。コメントファイルの書き換えは裏で行います。Ctrl+C で行の名前
    をコピーできます。

自動タグ
    フォルダ名、カメラ (EXIF)、形 (縦長・横長・正方形)、他のプログラムが付けた
    キーワードのタグを索引が自動で付けます ([設定 | 索引 | 自動タグ])。キーワー
    ドは、画像の中の XMP (dc:subject) と IPTC のキーワード、画像の隣のサイドカー
    ファイル (「画像名.jpg.xmp」(digiKam・darktable など) と「画像名.xmp」
    (Lightroom など)) から読みます。階層のあるキーワード (「季節|春」) しかな
    い場合は最後の部分を使います。サイドカーファイルを書き換えると、索引はその
    画像のキーワードを読み直します。キーワードは手動で付けたタグと同じ名前なら
    同じタグとして表示・検索します (タグタブ、データタブ、検索ウィンドウ、「タ
    グを編集」の「使われているタグ」)。gexiv2 (Exiv2) を使ってビルドした場合は、
    撮影日時・カメラ・キーワードを Exiv2 が読める形式 (JPEG・HEIF・PNG・WebP・
    TIFF・RAW など) すべてから読みます。gexiv2 なしでは、EXIF は JPEG だけ、
    XMP は JPEG・PNG・WebP・TIFF だけです。数字だけのフォルダ名や DCIM はタグ
    にしません。タグにしたくないフォルダ名は「タグにしないフォルダ名」(「*」「?
    」が使えます) に加えるか、タグタブのフォルダの右クリックの「このフォルダ名
    をタグにしない」で加えます (設定ウィンドウを開いている間は使えません)。自
    動タグは索引の中にだけあり、コメントファイルには書きません。

新しい画像の通知とお知らせ
    索引を作るディレクトリに画像が増えると、デスクトップに通知します (まとめる
    時間、間隔、通知しないフォルダは [設定 | 索引 | 新しい画像])。ステータスバー
    の「お知らせ」ボタンには、前回からの新しい画像の枚数や、他のプログラムで移
    動された画像のコメントを移すかどうかの確認などが出ます。

行方不明の画像
    コメント (タグ) の付いた画像が見つからなくなると、起動ごとのログ (~/.local/
    share/gimageview/missing-*.log) に記録します。[ツール | 行方不明の画像] の
    一覧で、コメントを「移動先に付け直す」「別の画像に付け直す...」「コメント
    を削除」「ログから外す」ことができます。

2.7. 顔と人物

[設定 | 索引 | 顔] の「顔を認識するフォルダ」(索引を作るディレクトリの中) の画
像から、gimv-faces が顔を探し、似た顔をグループにまとめます。索引のあとで、ゆっ
くり動きます。OpenCV 4.8 以上を使ってビルドした場合だけの機能で、モデルファイ
ル (OpenCV の YuNet と SFace、約 40 MB) を ~/.local/share/gimageview/models に
置く必要があります (ファイル名と入手先は [設定 | 索引 | 顔] を見て下さい。設定
のページにも表示されます)。

人物タブ
    名前を付けた人 (人物のタグでまとめて表示)、名前の候補 (「名前？」)、名前の
    ないグループ、その他の顔、無視した顔を表示します。クリックでその人の写って
    いる画像を開きます。右クリックの「顔を表示...」で顔の一覧ウィンドウを開き
    ます (右クリックのメニューは 6.3.4)。

顔の一覧ウィンドウ
    左の欄に人物 (名前のないグループと候補も) が顔と名前で並び、右にその人の顔
    が並びます。顔を選んで (Ctrl+A で全て) 「名前を付ける」「この人で正しい」
    「この人ではない」「名前を外す」「無視する」を選びます。ダブルクリックで元
    の画像を開きます。見出しのボタンで、名前の変更 (同じ名前の人がいれば 1 人
    にまとめる)、名前のコピー、人物のタグ、人物の削除ができます。並び順は古い
    順・新しい順・その人らしくない順 (間違って入った顔を探すとき) から選びます。

顔パネル
    イメージビューの右クリックの「顔の編集」(P) で、画像の右にその画像の顔が並
    び、ここでも名前を付けられます。「＋」を押して画像の上をドラッグすると、見
    つからなかった顔 (小さい顔など) を手で加えられます。顔の右クリックで、その
    顔をクリップボードにコピーできます。

名前とコメントファイル
    顔に付けた名前は、画像のコメントファイルにも「person/名前」のタグで書かれ
    ます。索引を作り直しても、このタグから名前が顔に戻ります。タグタブの「人物
    名」のグループはこのタグです。

人物のタグ
    人に付けるタグ (所属する集まりなど) です。顔の一覧ウィンドウの「人物のタグ
    ...」で付けます。索引の中にだけ保存し、タグタブの「人物のタグ」と人物タブ
    のまとまりに使います。名前を変えると、そのタグの付いた人全員が変わります。

    手動で付けるタグと同じく、「/」で階層になります。「家族/親」は「家族」の下
    のタグです。タグタブの「人物のタグ」、人物タブ、検索ウィンドウでは木になり、
    親 (その親を付けた人がいなくても出ます) は下のタグの人の画像も数え、親を選
    ぶと下のタグの人も含めて表示します。データタブでは「人物: 家族 / 親」と部
    分ごとに並び、親の部分で親の画像を開きます。親の名前を変えると下のタグも一
    緒に変わります。タグタブでは、人物のタグをドラッグして別の人物のタグの上で
    離すと、その下へ移動するか統合するかを選べます (「人物のタグ」の行で離すと
    一番上へ)。「人物のタグ...」のダイアログでは親の部分を薄く表示し、他の人の
    タグの親の部分をクリックすると入力欄に「家族/」が入って、その下のタグだけ
    が候補に残ります。

2.8. 画像の検索

[ツール | 画像を検索...] で、索引から複数の条件で画像を探します。

 ・ 下の一覧のタグ (人物の名前、自動タグも) をクリックすると、条件が札になって
    上に並びます。入力欄に文字を入れると一覧を絞り込み、Enter で先頭のタグを加
    えます。札の条件は全て満たす (かつ) 画像を探します。札をクリックすると「除
    く」(赤) に変わり、そのタグの付いた画像を外します。× で札を外します。

 ・ 「撮影日」で撮影日の範囲を指定します (年だけ、年月だけでも構いません)。

 ・ 条件を加えると、下の一覧は見つかった画像に付いているタグを種類ごとに件数付
    きで並べます。クリックでさらに絞り込み、各行の「除く」で外せます。

 ・ 「旅行/京都」のように「/」のあるタグは、タグタブと同じく木になります。親の
    件数は下のタグの画像も数え (画像に直接付いていない親も出ます)、▸ で下のタ
    グを開きます。親をクリックすると、その親か下のタグの付いた画像に絞り込みま
    す。親が条件になると、下のタグ (「旅行/京都」) が一覧の一番上の段に出るの
    で、続けて絞り込めます。入力欄に文字を入れると、名前の最後の部分 (「寺」)
    が合うタグと、その親までを開いて表示します (「/」を含めて入力したときは名
    前全体で探します)。

 ・ 見つかった画像はサムネイルウィンドウのタブに表示します。

 ・ 「保存...」で今の条件に名前を付けて保存し、上のドロップダウンから呼び出せ
    ます (~/.gimv/searches)。ごみ箱のボタンで削除します。

2.9. その他

 ・ イメージビューの右クリックの「画像をクリップボードにコピー」(Shift+Ctrl+C)
    で、表示している画像を他のプログラムに貼り付けられます。

 ・ イメージビューの「左右反転」(X) と回転は画像ごとに記憶し、次に開いたときに
    戻します ([設定 | イメージウィンドウ | 画像] の「画像ごとに回転・左右反転
    を覚える」)。

 ・ サムネイルビューとイメージビューの右クリックの「元のフォルダを開く」で、画
    像のあるフォルダを開きます。

3. 目的別の操作
===============

やりたいことから操作を探すための章です。それぞれ手順の要点だけを書いています。
詳しくはリンク先を見て下さい。索引・顔の機能は、それを使ってビルドした場合だけ
です。

3.1. 索引を使う準備

日付・タグで画像を探せるようにしたい
    [設定 | 索引] の「索引を作るディレクトリ」に、写真を置いているフォルダを加
    えます。GImageView を起動している間に索引ができていき、ディレクトリビュー
    の欄に「日付」「タグ」のタブが増えます。進み具合はステータスバーの右端に出
    ます。SQLite を使ってビルドした場合だけの機能です。

    詳しくは 2.6. 画像の索引、[設定 | 索引] を見て下さい。

写っている人で画像を探せるようにしたい
    [設定 | 索引 | 顔] の「顔を認識するフォルダ」を指定し、モデルファイルを置
    きます。索引のあとで顔を探し、似た顔をまとめた「人物」タブができます。
    OpenCV を使ってビルドした場合だけの機能です。

    詳しくは 2.7. 顔と人物、[設定 | 索引 | 顔] を見て下さい。

3.2. タグを付ける・整理する

何枚かの画像にまとめてタグを付けたい
    サムネイルビューで画像を選びます。Ctrl+クリックで 1 枚ずつ加え (もう一度で
    外す)、Shift+クリックでその間を全部、画像のない所からドラッグで囲んだ画像
    を選びます。Ctrl+A で全て選択です。選んだら右クリックの「タグを編集...」か
    [編集 | タグを編集...] で、タグを入力して Enter、何も入力していないときの
    Enter で決定です。選んだ枚数はステータスバーに「n 枚選択」と出ます。

    詳しくは タグを付ける、全て選択 を見て下さい。

フォルダの中の画像すべてにタグを付けたい (下のフォルダも含めて)
    ディレクトリビューでフォルダを右クリックし、「下のフォルダも含めてタグを編
    集...」を選びます。フォルダを開いたり画像を選んだりする必要はありません。
    枚数が多いときは進み具合が出て、「中止」で止められます。

    詳しくは タグを付ける、ディレクトリビューのマウスメニュー を見て下さい。

何枚かの画像からタグを外したい
    画像を選んで「タグを編集...」を開くと、一部の画像にだけ付いているタグは
    「京都 2/5」のように出ます。× を押すと選んだ画像の全部から外れ、クリックす
    ると全部に付きます。触らなければ各画像のままです。

    詳しくは タグを付ける を見て下さい。

タグの名前を変えたい・2 つのタグを 1 つにまとめたい
    タグタブでタグを選び、F2 か右クリックの「名前を変更...」で名前を変えます。
    すでにある名前にすると、1 つにまとめるか聞かれます。タグタブの中でタグをド
    ラッグして別のタグの上で離しても、まとめられます。

    詳しくは タグの名前の変更・統合 を見て下さい。

タグを階層に分けて整理したい (「旅行/京都」)
    タグの名前に「/」を入れると階層になります。今あるタグは、タグタブでドラッ
    グして親にしたいタグの上で離し、「「旅行」の下へ移動」を選びます。親をクリッ
    クすると、下のタグの画像もまとめて開きます。

    詳しくは タグタブ を見て下さい。

3.3. 画像を探す

あるタグの付いた画像を見たい
    タグタブでタグをクリックすると、結果のタブに表示します。中ボタンのクリック
    で新しいタブに開きます。コメントウィンドウやプレビューの「データ」タブのタ
    グをクリックしても開けます。

    詳しくは 開き方 を見て下さい。

撮影した日から画像を探したい
    日付タブで年・月・日を開いてクリックします。撮影日の分からない画像 (SNS の
    画像など) は、「データ」タブの「日付」に日付を書くと、その日として扱われま
    す。

    詳しくは 日付タブ、2.9. その他 を見て下さい。

いくつかの条件を組み合わせて探したい (「京都」で「猫」のない画像など)
    [ツール | 画像を検索...] で、タグ・人物・撮影日の期間を組み合わせます。タ
    グをクリックすると条件になり、条件の札をクリックすると「除く」に変わります。
    よく使う条件は「保存...」で名前を付けて残せます。

    詳しくは 2.8. 画像の検索 を見て下さい。

見つけた画像のあるフォルダを開きたい
    サムネイルビューかイメージビューの右クリックの「元のフォルダを開く」です。
    結果のタブはファイル名だけを表示しますが、フルパスはツールチップとステータ
    スバーに出ます。

    詳しくは 開き方 を見て下さい。

3.4. 人物

同じ人が写っている画像を集めたい
    人物タブでその人 (名前のないグループも) をクリックします。顔を確かめたいと
    きは右クリックの「顔を表示...」で顔の一覧ウィンドウを開きます。

    詳しくは 人物タブ を見て下さい。

顔に名前を付けたい・間違った顔を外したい
    顔の一覧ウィンドウで顔を選び (Ctrl+A で全て)、「名前を付ける」「この人では
    ない」などを選びます。並び順を「その人らしくない順」にすると、間違って入っ
    た顔が上に来ます。1 枚の画像なら、イメージビューの右クリックの「顔の編集」
    (P) でも名前を付けられます。

    詳しくは 顔の一覧ウィンドウ、顔パネル を見て下さい。

見つからなかった顔を加えたい
    イメージビューの右クリックの「顔の編集」(P) で顔パネルを出し、「＋」を押し
    て画像の上の顔をドラッグで囲みます。

    詳しくは 顔パネル を見て下さい。

3.5. 画像の整理

重複している画像を探して片付けたい
    別のフォルダにある同じファイルは [ツール | 索引から重複画像を探す...] で、
    索引の全部の画像から探せます (フォルダの下だけならディレクトリビューの右ク
    リック、ある画像と同じものならサムネイルの右クリックの「同じファイルを探す」
    )。大きさ違いや似ている画像は、探したい画像をタブに開いて [ツール | 重複画
    像を探す...] です。グループごとに「残す」「削除」を確かめてゴミ箱へ移せ
    (ゴミ箱から戻せます)、「全部のグループの削除をゴミ箱へ...」でまとめても移
    せます。ファイル名を残したいときは、確認で「ゴミ箱へ移してリンクを残す」を
    選ぶと、その名前は残す画像へのリンクになります。

    詳しくは 索引から重複画像を探す、重複画像を探す を見て下さい。

移動した画像のタグやコメントを付け直したい
    GImageView で移動した画像は、タグやコメントも一緒に移ります。他のプログラ
    ムで移動して見つからなくなった画像は [ツール | 行方不明の画像...] に出るの
    で、「移動先に付け直す」などを選びます。

    詳しくは 行方不明の画像 を見て下さい。

気になる画像に印を付けて、後で見返したい
    画像を選んで右クリックの「ブックマーク...」を選びます。メモも書けます。付
    けた画像はディレクトリビューの並びの「ブックマーク」タブ (星) から、付けた
    日ごとに開けます。

    詳しくは 2.5. ブックマーク を見て下さい。

ブックマークに後からメモを付けたい
    ブックマークのタブ (星) の「メモなし」をクリックすると、メモのない画像が結
    果のタブに並びます。画像を選んで、もう一度右クリックの「ブックマーク...」
    (または [編集 | ブックマーク...]) を選ぶと、メモの欄が出ます。書いて Enter
    で保存します (欄の外をクリックしたり Esc で閉じたりしても、書いた内容は保
    存されます)。すでにメモがあれば、そのメモが入った状態で開くので書き直せま
    す。

    何枚か選ぶと、書いたメモが選んだ画像すべてに付きます (前のメモは置き換わり
    ます。何も書かずに閉じれば、それぞれのメモはそのままです)。

    詳しくは 2.5. ブックマーク、6.3.5. ブックマークのタブ を見て下さい。

よく見るフォルダや書庫をすぐ開きたい
    ディレクトリのタブでフォルダを右クリックして「ブックマーク...」を選びます
    (サムネイルビューに出ているフォルダ・書庫は、画像と同じく右クリックの「ブッ
    クマーク...」)。ブックマークのタブ (星) の「フォルダ・書庫」の下のフォルダ・
    書庫をクリックすると開きます。

    詳しくは 2.5. ブックマーク を見て下さい。

ブックマークした画像が「見つからない」になった
    GImageView を起動していない間に移動・名前の変更・削除したものです。ブック
    マークのタブ (星) の「見つからない」をクリックすると一覧が開き、索引にある
    同じ名前のファイルを移動先の候補に出します。「移動先に付け直す」か「別の場
    所に付け直す...」でメモごと付け直し、消したものは「ブックマークを外す」で
    外します。

    詳しくは 2.5. ブックマーク (移動と行方不明) を見て下さい。

写真の一部を拡大して見たい (ルーペ)
    イメージウィンドウやプレビューで、Ctrl を押しながら左ボタンを押したままに
    すると、カーソルの位置に拡大した四角が出ます。押したままカーソルを動かすと
    付いてきて、ホイールで倍率 (100%・200%・400%…) が変わります。離すと消えま
    す。

    詳しくは 7.2.2. マウスボタン を見て下さい。

画像を別の形式で保存したい (HEIC を JPEG に、など)
    イメージウィンドウの [ファイル | 画像を保存...] (Ctrl+S) か、プレビューの
    右クリックの「画像を保存」で、形式と画質を選んで保存します。

    詳しくは 画像を保存 を見て下さい。

写真を小さくして容量を減らしたい
    サムネイルで画像を選び、右クリックの「縮小して保存...」で、高さ 800 px 以
    下などに縮めた画像を別のファイルとして保存します (元の画像はそのままです)。
    位置情報を除いて保存することもできます。

    詳しくは 縮小して保存 を見て下さい。

何枚かの画像を 1 枚につなげたい (分けて撮った写真など)
    サムネイルで画像を選び、右クリックの「画像を連結...」で、縦・横・格子状に
    並べた画像を別のファイルとして保存します。1 枚の写真を分けたもので重なる部
    分があれば、自動で探して重ね、ずれていれば手で直せます。

    詳しくは 画像を連結 を見て下さい。

スキャンした画像のまわりの背景を切り取りたい
    画像を表示して C (またはマウスメニューの「切り抜き」) を押し、「端を検出」
    で、まわりの背景 (白や黒など一色の縁) を除いた範囲を選びます。枠を手で直し、
    Enter で「名前_crop.jpg」として保存します (元の画像はそのままです)。枠をド
    ラッグして好きな部分を切り抜くこともできます。

    詳しくは 切り抜き を見て下さい。

3.6. 使い勝手

漫画を見開きで読みたい
    フォルダや書庫 (zip・cbz・rar・lzh など) を開いて最初のページを選び、プレ
    ビューの右クリックの [見開き | 見開き] か T キーで見開きにします。クリック
    (左半分で次、右半分で前) かスペースでめくります。左右が合わないときは O キー
    で 1 ページずらします。4 ページずつなど並べ方を変えるには [見開き | 並べ方]
    から選びます (並べ方は [見開き | 並べ方を編集...] で増やせます)。

    詳しくは 見開き を見て下さい。

ショートカットキーを変えたい
    [編集 | キーボードショートカット...] で、行のキーをクリックして新しいキー
    を押します。上の欄で名前やキーで絞り込めます。

    詳しくは キーボードショートカット を見て下さい。

長い一覧から名前で探したい
    ディレクトリビューやタグタブ、詳細表示などで Ctrl+F を押し、名前を入力しま
    す。

    詳しくは 一覧の検索 を見て下さい。

4. メニューバー
===============

ここではメニューバーの各項目について説明します。メニューバーはサムネイルウィン
ドウとイメージウィンドウの両方に存在しますが、ここでは一緒に扱います。なお、片
方のウィンドウにしかない項目には、「サムネイルウィンドウのみ」「イメージウィン
ドウのみ」と表記しています。項目名の後の [ ] 内は、既定のショートカットキーで
す。

4.1. ファイル

開く [Ctrl + F]
    ファイルオープンダイアログを表示します。

    「選択したファイルを開く」と、イメージウィンドウを新規に作成し、画像を展開
    します。

    「選択したファイルのサムネイル」とすると、コレクションタブが新規に生成され、
    そこにコレクション(サムネイル表示)されます。選択したフォルダ (ディレクトリ)
    は、フォルダごとに新しいタブで開きます (ディレクトリビューでダブルクリック
    した時と同じです)。ファイルとフォルダを一緒に選んだ場合は、ファイルはコレ
    クションタブに、フォルダはそれぞれのタブに表示されます。

新規イメージウィンドウ [Ctrl + I]
    空のイメージウィンドウを新規に作成します。

新規ウィンドウ [Ctrl + W]
    サムネイルウィンドウのみ。サムネイルウィンドウを新規に作成します。

新規サムネイルウィンドウ [Ctrl + W]
    イメージウィンドウのみ。サムネイルウィンドウを新規に作成します。

新規タブ [Ctrl + T]
    サムネイルウィンドウのみ。空のタブを新規に生成します。

メモリバッファ [Ctrl + B]
    イメージウィンドウのみ。展開している画像をメモリバッファに保持します。メモ
    リバッファについての詳しい説明は、Tips の「イメージビューの描画を速くする」
    を参照してください。

画像を保存 [Ctrl + S]
    イメージウィンドウのみ。表示している画像を、形式を指定して別のファイルに保
    存します (HEIC を JPEG にする、など)。サムネイルウィンドウのプレビューのマ
    ウスメニューの「画像を保存」も同じです。

     ・ 保存先: 初めは元の画像と同じフォルダ・同じ名前で、形式の拡張子にしたも
        のです (元の画像と同じになる場合は名前に「_2」を付けます)。「参照...」
        でファイル選択のダイアログから選べます。同じ名前のファイルがあれば、上
        書きするか確認します。

     ・ 形式: JPEG・PNG・WebP・AVIF・TIFF・BMP・PNM のうち、保存できるものが出
        ます (WebP・AVIF などは gdk-pixbuf の書き出し機能があるとき)。

     ・ 画質: JPEG・WebP・AVIF の画質 (1〜100、初期値 90) です。

     ・ 撮影日時・カメラなどの情報 (EXIF・XMP・IPTC) を残す: gexiv2 (Exiv2) を
        使って作成した場合の項目です。元のファイルの情報を新しいファイルにコピー
        します (JPEG・PNG・WebP・TIFF)。画像は表示している向きで保存するので、
        情報の「向き」は標準にし、EXIF の縮小画像は除きます。

    画像は元の大きさで、表示している向き (回転・左右反転) のまま保存します。保
    存は別スレッドで行います。保存したフォルダをサムネイルウィンドウで開いてい
    れば、一覧を更新します。選んだ形式と画質は、gimv を終了するまで覚えていま
    す。

印刷 [Ctrl + P]
    サムネイルウィンドウでは、サムネイルビューで選択されている画像を印刷します。
    1 枚の画像を 1 ページに印刷します。画像が選択されておらず、プレビューに画
    像が表示されている場合は、その画像を印刷します。

    イメージウィンドウでは、表示している画像を回転した向きで印刷します。

タブを閉じる [Q]
    サムネイルウィンドウのみ。アクティブになっているタブを閉じます。

ウィンドウを閉じる [Ctrl + Q] / 閉じる [Q]
    サムネイルウィンドウの「ウィンドウを閉じる」は、サムネイルウィンドウを閉じ
    ます。この時、展開されているイメージウィンドウはそのまま残ります。イメージ
    ウィンドウの「閉じる」は、そのイメージウィンドウを閉じます。

終了 [Ctrl + C]
    GImageView に関する、全てのウィンドウを閉じます。

    サムネイルウィンドウ・イメージウィンドウが複数ある場合、それらは全て閉じら
    れます。

4.2. 編集

全て選択 [Ctrl + A]
    サムネイルウィンドウのみ。アクティブになっているタブ内のファイルを「全て選
    択」します。

全て選択解除 [Ctrl + N]
    サムネイルウィンドウのみ。アクティブになっているタブの「選択解除」を行いま
    す。

    GImageView は、タブごとに選択(非選択)状態を保持しています。「全て選択解除」
    を行っても、アクティブになっていないタブについては、選択解除を行いません。

リスト更新 [Shift + Ctrl + R]
    サムネイルウィンドウのみ。アクティブになっているタブの「リスト更新」を行い
    ます。

キャッシュ再読込 [Shift + R]
    サムネイルウィンドウのみ。アクティブになっているタブの「キャッシュを再読込」
    を行います。

全てのサムネイルを再作成 [Ctrl + R]
    サムネイルウィンドウのみ。アクティブになっているタブの「サムネイルを再作成」
    を行います。表示している部分から作り直し、残りは裏で作り直します。作り直し
    ている間は進み具合 (n/N) が表示され、ツールバーのストップボタンで止められ
    ます。表示位置はそのままです。

    「リスト更新」「キャッシュを再読込」「サムネイルを再作成」の違いについては、
    Tips の「[リスト更新]・[キャッシュ再読込]・[全てのサムネイルを再作成]の違
    いについて」を参照してください。

ファイル名変更 [Shift + E]
    サムネイルウィンドウのみ。サムネイルビューで選択されている画像(ファイル)の
    名前を変更します。

    変更するのは拡張子を除いた名前で、拡張子 (.jpg など) はそのまま残ります
    (拡張子がなくなると画像として表示されなくなるため)。拡張子も変えたい時は
    「拡張子も変更する」をチェックすると、全体を編集できます。その時、新しい名
    前に画像の拡張子がなければ確認し、もう一度 [拡張子なしで変更] を押すとその
    まま変更します。同じ名前のファイルがある時は、赤字で知らせて変更しません
    (上書きはしません。別の名前にして下さい)。

    複数の画像を選んでいる時は、まとめて名前を変える「ファイル名の変更」ウィン
    ドウが開きます。上のボタンで、何をしたいかを選びます (ボタンの下に例が出ま
    す)。

     ・ 番号を付ける: 「名前」の後に番号を付けます (例: 旅行_001.jpg、旅行
        _002.jpg)。開始番号と桁数、番号の順 (一覧の並び順・撮影日の順・名前の
        順) を選べます。名前の初めはフォルダ名です。

     ・ 撮影日時の名前: 撮影日時を名前にします (例: 2026-11-25_203012.jpg)。撮
        影日は索引 (コメントの日付・EXIF など) か EXIF から読み、ない画像は名
        前の中の日付 (IMG_20190503_101500.jpg など)、それもなければファイルの
        日付を使います (一覧に「撮影日がないため名前の中の日付」「撮影日がない
        ためファイルの日付」と出ます)。同じ日時の画像には _2、_3 … を付けます。
        後ろに文字を付けることもできます。

     ・ 文字を置き換える: 名前の中の文字を別の文字にします (例: IMG_ → 旅行_)。
        置き換える文字を空にすると取り除きます。「詳しい設定」を開くと、正規表
        現と大文字・小文字の区別を選べます。

     ・ 文字を足す: 名前の前か後ろ (拡張子の前) に文字を足します。

    入力するとすぐに、一覧に「今の名前 → 新しい名前」が出ます。拡張子はそのま
    まです (「拡張子を小文字にそろえる」で .JPG を .jpg にできます)。同じ名前
    のファイルがある、ほかのファイルと同じ名前になる、名前が入れ替わる (2 回に
    分けて変えて下さい)、ファイル名に使えない、という名前は赤字で示し、直すま
    で変更できません。上書きはしません。番号をずらす時 (1 → 2、2 → 3) のように、
    まとめて変える別のファイルの今の名前になるのはかまいません (先にそちらを変
    えます)。

    [N 個のファイルの名前を変える] で変更した後は、[元に戻す] で一度だけ元の名
    前に戻せます。gimv で名前を変えると、サムネイルのキャッシュ・コメント (手
    動で付けたタグを含む)・ブックマークも新しい名前に移り、索引も名前の変更に
    追従します。ファイルの日付は変わりません。

ファイル名を UTF-8 に変換
    サムネイルウィンドウのフォルダのタブのみ。名前が UTF-8 でないファイル (MS-
    DOS 時代の Shift_JIS や UNIX の EUC-JP で付けられた名前。一覧では斜体か %XX
    で表示されます。7.1.2) の名前を、まとめて UTF-8 に変えます。

    ファイルごとに、今の名前のバイト列、文字コード (推定したもの。Shift_JIS・
    EUC-JP・ISO-2022-JP・ISO-8859-1 から選び直せます) と新しい名前を表示します。
    新しい名前を確かめて [N 個のファイルの名前を変える] を押します。新しい名前
    のファイルがすでにあるもの、ほかのファイルと同じ名前になるもの、その文字コー
    ドで読めないものは変換しません (上書きはしません)。サムネイルのキャッシュ、
    コメント、ブックマークも一緒に移ります。

ディレクトリへコピー [Shift + C]

    コピーします。

サムネイル作成 [Shift + T]
    イメージウィンドウのみ。表示している画像のサムネイルを、[設定 | サムネイル

切り抜き [C]
    イメージウィンドウのみ。表示している画像の一部を切り抜いて、別のファイルと
    して保存します。元の画像は変わりません。イメージビューとプレビューのマウス
    メニューの「切り抜き」も同じです。

    画像の上に切り抜く範囲の枠 (初めは画像全体) と、画像の上にバーが出ます。枠
    の外は暗く表示します。

     ・ 枠の中をドラッグすると枠が動き、辺や角 (白い四角) をドラッグすると大き
        さが変わります。枠の外 (枠が画像全体の時は中も) をドラッグすると新しい
        枠を描きます。画像の外のドラッグはこれまでどおりスクロールです。

     ・ 端を検出: まわり (画像の端) と同じ色の縁を除いた範囲を枠にします。A4
        で読み取った小さな物や黒い布の上で撮った物のように、まわりが一色 (白や
        黒など) の画像に使います。スキャナの端の影やゴミは無視し、少し余白を残
        します。結果は枠として出るので、手で直してから保存できます。

     ・ 設定 (≡): 端の色との差の許容 (初期値 40。ノイズが多ければ大きく、物の
        色が薄ければ小さく)、余白 (px、初期値 8)、画質 (JPEG・WebP、初期値 90)、
        ファイルの情報 (EXIF など) を残すか、コメントと手動で付けたタグを引き
        継ぐかです。

     ・ 縦横比: 自由・元の画像と同じ・1:1・4:3・3:2・16:9。縦長か横長かは枠に
        合わせます。

     ・ 枠の大きさを元の画像のピクセル数で表示します。

     ・ 保存 [Enter]: 元の画像と同じフォルダに「名前_crop.jpg」(形式は元のまま。
        gdk-pixbuf が書けない形式は JPEG、透過があれば PNG、MAG・Pi など gimv
        独自のローダで読む形式は PNG。PNG では元のファイルに書かれたコメントを
        引き継ぎ、MAG・Pi などでは情報を残す設定のとき、ファイルの更新日時を
        EXIF の DateTime に書きます) で保存します。同じ名前があれば -1, -2 な
        どを付けて、上書きはしません。保存すると下に「表示」のボタンが出て、サ
        ムネイルウィンドウで新しい画像を選べます。

     ・ やめる [Esc]: 切り抜きをやめます。別の画像に移ったり、回転したりしても
        やめます。

    画像は元の大きさで、表示している向き (回転・左右反転) のまま切り抜きます。
    読み込み・端の検出・保存は別スレッドで行います。

タグを編集
    画像の索引が使える場合にある項目です。選択している画像 (イメージウィンドウ
    では表示している画像) のタグを編集します (2.6)。標準ではキーはありません。

ブックマーク
    選択している画像 (イメージウィンドウでは表示している画像) をブックマークし、
    メモの欄を出します (2.5)。標準ではキーはありません。

設定 [Ctrl + O]
    設定ダイアログを表示します。

    設定内容の詳細は、項7を参照してください。

キーボードショートカット...
    サムネイルウィンドウ (プレビューも) と画像ウィンドウのメニュー項目のキーと、
    その他のキー (右ボタンメニュー、パスの補完、ナビゲーター、サムネイルウィン
    ドウの表示形式) を一覧し、変更します。行のキーをクリックすると開くウィンド
    ウで新しいキーを押します (Esc や BackSpace も含め、どのキーでも。押し直せ
    ば変わります)。キーの下に、そのキーが今どう使われているか (同じウィンドウ
    や別のウィンドウの別の項目のキー、画像の矢印キーや PageUp/PageDown など
    gimv が直接使っているキー、未使用) を表示するので、キーを押してみて空いて
    いるかを調べられます。[了解] で決め、[キーなし] でキーを外し、[キャンセル]
    でそのままにします。同じウィンドウの別の項目のキーだったときは、そちらから
    外すか確認します。行の戻すボタンか「すべて標準に戻す...」で標準のキーに戻
    ります。変えたキーはすぐに使え (表示形式のキーは次回の起動から)、~/.gimv/
    keyaccelrc か ~/.gimv/keyconf に保存されます。上の入力欄で名前やキーの一部
    (「ctrl+t」) で絞り込めます。

4.3. 表示

ファイルソート
    サムネイルウィンドウのみ。サムネイルビューを指定した順でソートします。

    ここでの指定は、アクティブになっているタブと指定した後に開く全てのタブに対
    して有効です。

    GImageView は、選択(非選択)状態と同様に、タブごとに並び順を保持しています
    ので、開いていないタブについては、それまでのソート順が維持されます。なお、
    指定できる順は以下のとおりです。

     ・ 名前

     ・ 参照日時

     ・ 更新日時

     ・ 撮影日 (画像の索引の撮影日: コメントの「日付」、EXIF、ファイル名の日付、
        更新日時の順。索引の外の画像は更新日時。新しい順にするには「逆順」も指
        定します)

     ・ 状態変更日時

     ・ サイズ

     ・ 種類

     ・ 画像幅

     ・ 画像高さ

     ・ 画像面積

     ・ ブックマーク (ブックマークを付けた画像が先で、それぞれ名前順。「逆順」
        では付けていない画像が先)

    このほか、「逆順」「大文字小文字を区別しない」「ディレクトリを区別しない」
    「数字を数の大きさで並べる」を指定できます。

    「数字を数の大きさで並べる」(既定でオン) では、名前の中の数字を文字ではな
    く数として比べます。0p.jpg・1.jpg・2.jpg・10.jpg のように並び、10.jpg が
    2.jpg の前に来たり、0p.jpg が 09.jpg の後に来たりしません。値が同じなら 0
    の少ないほうが先です (1.jpg・01.jpg)。

レイアウト
    サムネイルウィンドウのみ。サムネイルウィンドウの各ビュー(ディレクトリ・サ
    ムネイル・プレビュー)のレイアウトを変更します。レイアウト0〜4 (Ctrl + 0〜
    4)、カスタムから選択する事ができます。なお、カスタムレイアウトについての詳
    細は、Tips の「カスタムレイアウトについて」を参照してください。

    GTK 4 版では、各レイアウトは配置を表す絵のボタンで並べて表示されます。絵の
    文字は、D がディレクトリビュー、T がサムネイルビュー、P がプレビューを表し
    ます。ボタンにマウスを乗せると、名前とショートカットキー (Ctrl + 0〜4) が
    表示されます。カスタムの絵は、その時点のカスタムレイアウトを表します。

レイアウト | ウィンドウ構成
    サムネイルウィンドウのみ。サムネイルウィンドウ内の各ビュー(ディレクトリ・
    サムネイル・プレビュー)の配置を、あらかじめ用意されている構成から選択しま
    す。

    GTK 4 版では、各構成は配置を表す絵のボタンで並べて表示されます。ボタンにマ
    ウスを乗せると名前が表示されます。

スライドショー [Ctrl + S]
    サムネイルウィンドウのみ。アクティブになっているタブについて、スライドショー
    を行います。

    スライドショーについての設定は、項7.5で行ってください。

スライドショーオプション
    サムネイルウィンドウのみ。スライドショーの順序と対象を指定します。

     ・ 最初から開始 / 選択画像から開始 / ランダム順 : 表示する順序です。

     ・ 選択画像のみ : 選択されている画像だけを表示します。

     ・ 画像と動画 / 画像のみ / 動画のみ : 表示するファイルの種類です。

ズーム
    イメージウィンドウのみ。表示している画像のズーム(拡大縮小)、「アスペクト比
    の保持」設定などを行います。

    拡大 [S]、縮小 [A]、ウィンドウの大きさに合わせる [W]、幅を合わせる [Shift
    + W]、高さを合わせる [Shift + H]、アスペクト比を保持 [Shift + A] と、10〜
    200% [1〜9] があります。これ以外の倍率については、ツールバーから直接指定し
    てください。

    「アスペクト比を保持」にチェックが入っている場合、画像を拡大縮小した時に、
    画像のアスペクト比が保持されます。

回転
    イメージウィンドウのみ。表示している画像を回転します (画像ファイルは書き換
    えません)。時計回りに90°回転 [R]、反時計回りに90°回転 [E]、180度回転 [D]
    の3種類と、左右反転 [X] があります。回転と左右反転は画像ごとに覚え、次に開
    いた時に同じ向きで表示します (画像ごとに回転・左右反転を覚える)。

アルファチャンネルを無視
    イメージウィンドウのみ。画像の透過情報を使わずに表示します。

透過部分を市松模様で表示
    イメージウィンドウのみ。透過のある画像の背景を、灰色の市松模様で表示します。
    初期状態は [設定 | イメージウィンドウ] の画像の透過部分を市松模様で表示す
    るに従います。

ディレクトリビュー [Shift + D]
    サムネイルウィンドウのみ。ディレクトリビュー表示 ON/OFF です。

プレビュー [Shift + P]
    サムネイルウィンドウのみ。プレビューの ON/OFF です。

メニューバー [M]
    メニューバー表示 ON/OFF です。

ツールバー [N]
    ツールバー表示 ON/OFF です。

    イメージウィンドウのみ。スライドショー操作用のツールバー表示 ON/OFF です。

タブ (プレビュー) [Shift + Z]
    サムネイルウィンドウのみ。プレビューのタブ表示 ON/OFF です。

プレーヤ
    動画・音声の再生用ツールバーの表示を、「表示」「非表示」「自動」から選びま
    す。「自動」では動画・音声を表示している時だけ表示します。

見開き
    本や漫画のように、ページを並べて表示します (プレビューとイメージウィンドウ。
    プレビューでは右クリックのメニューから)。既定は 2 ページの見開きで、4 ペー
    ジなど並べ方を変えられます。手で切り替えるもので、フォルダや書庫によって自
    動では始まりません。

     ・ 見開き [T] : 見開き表示の ON/OFF。選んでいる画像と、一覧でその後の画像
        を並べます。

     ・ 並べ方 : 並べ方を選びます。最初は「見開き (2 × 1)」と「4 ページ (2 ×
        2)」があります。「横に並べるページ数 × 段数」で、選んだ並べ方はそのウィ
        ンドウで使い、次に開くウィンドウにも使います。

     ・ 右から左へ (漫画) : ON で、選んでいる画像を右に、次の画像をその左に並
        べます。OFF で左から右へ並べます。段があるときは、上の段から順に並べま
        す。今の並べ方の設定です。

     ・ 1 ページ目は単独 : ON で、一覧の最初の画像 (表紙) を 1 枚だけで表示し
        ます。今の並べ方の設定です。

     ・ 1 ページずらす [O] : 1 ページ進めて、ページの組み合わせをずらします。
        見開きの左右が合わない本で使います。

     ・ 並べ方を編集... : 並べ方の一覧を編集するウィンドウを開きます。並べ方ご
        とに、名前・横に並べるページ数 (1〜4)・段数 (1〜3)・右から左へ・1 ペー
        ジ目は単独を設定でき、追加・削除・順番の入れ替えができます。変更はすぐ
        に表示に反映され、設定に保存されます。名前はメニューとステータスバーに
        出ます。

    次の画像 (クリック・スペース・PageDown) で次のページへ、前の画像 (PageUp)
    で前のページへ進みます。左ボタンのクリックは、クリックした側で決まります。
    右から左の本では左半分で次へ、右半分で前へ進みます (左から右では逆)。マウ
    スを画像の上に置くと、その側に「◀ 次へ」「前へ ▶」のように行き先が出ます。
    ページは最初のページと同じ高さにそろえて、間をあけずに並べます。横長の画像
    (見開きで 1 枚の画像) は 1 枚だけで表示し、その前のページまでで区切ります。

    ページを並べて表示している間は、サムネイル作成・切り抜き・顔の編集はできま
    せん (ページの画像ではないため)。

    見開きで見ていた本 (フォルダや書庫) は、最後に表示したページと並べ方を覚え
    ておき (~/.gimv/books、最近の 1000 冊)、次にその本のタブを開いたときにその
    ページを選んで、プレビューに見開きで表示します (続きから)。本の中で見開き
    を切ると、その本の記録は消えます。見開きはそれを入れたタブ (本) の中だけで
    有効で、ほかのタブや日付・タグなどの一覧から画像を開くと 1 ページで表示し
    ます。見開きにしていた本のタブで画像を開き直すと、また見開きになります。そ
    のタブを閉じると見開きは切れます (本の記録は残ります)。見開きの間は、次に
    めくるページを別スレッドで先に読んでおきます (GdkPixbuf で読める形式。書庫
    の中の画像は先に展開します)。

    イメージウィンドウで「自動的に画像のサイズにリサイズする」がオンのときは、
    表紙を 1 枚だけ表示しているときも、並べ方の枚数分 (2 × 2 なら 4 ページ分)
    の大きさにウィンドウを合わせます。大きさを合わせるのは見開きにしたとき・並
    べ方を変えたとき・別のフォルダに移ったときだけで、ページをめくってもウィン
    ドウの大きさは変わりません ([表示 | 画像の大きさに合わせる] でいつでも合わ
    せ直せます)。

    見開きの間は、ステータスバーの右に「見開き 2-3 / 8」(並べ方の名前と、全 8
    ページのうち 2〜3 ページ目) や「見開き 6 (単独) / 8」(6 ページ目を 1 枚で
    表示) と出ます。プレビューではサムネイルウィンドウのステータスバーに出ます。
    イメージウィンドウでは、ツールバーの見開きボタンでも切り替えられます。

画像の大きさに合わせる [I]
    イメージウィンドウのみ。イメージウィンドウを、表示している画像の大きさにリ
    サイズします。ツールバーの[ウィンドウの大きさを画像に合わせる]と同じです。

    画像の表示倍率は変わりません。リサイズされるのはイメージウィンドウの方です。

最大化 [F]
    ウィンドウの最大化 ON/OFF です。

全画面 [Shift + F]
    イメージウィンドウのみ。全画面表示 ON/OFF です。

4.6. ツール

サムネイルウィンドウのみのメニューです。

全てのキャッシュをクリア
    [設定 | サムネイルキャッシュ] の「キャッシュ書込タイプ」の形式のサムネイル
    キャッシュを、全て削除します。

行方不明の画像
    コメント (タグ) の付いた画像のうち、見つからなくなったものの一覧を開きます。
    コメントを移動先や別の画像に付け直したり、削除したりできます (2.6)。画像の
    索引が使える場合だけのメニューです。

画像を検索
    索引から、タグ・人物・撮影日の期間を組み合わせて画像を探すウィンドウを開き
    ます (2.8)。画像の索引が使える場合だけのメニューです。

重複画像を探す
    アクティブなタブの全ての画像から重複している画像を探し、結果のウィンドウを
    開きます (ファイルの選択は関係ありません)。1 回で次の種類に分けて探します。

     ・ 完全に同じ: 中身がまったく同じファイル。

     ・ 大きさ違い: 同じ写真で大きさ (画素数) だけが違うもの。縦横比が同じで、
        同じ大きさのものがないとき。同じファイルも含みます。

     ・ 同じピクセル: 画素は全く同じで、メタデータ (撮影情報・コメントなど) や
        形式だけが違うもの。

     ・ 保存し直し: 同じ絵を別の画質・形式・大きさで保存し直したもの (JPEG の
        圧縮のノイズだけが違う)。

     ・ 明るさ・色違い: 同じ絵で、全体が少し明るい・暗い・色が違うもの。

     ・ 一部が違う: 一部だけが違うもの (差分の表情や服、書き込み、印など)。

     ・ 似ている別の画像: 似ているが別の画像 (続きのページ、続けて撮った写真な
        ど)。

    どの程度似ていれば見つけるかは [設定 | 検索] の「精度」です。同じ大きさで
    似ているものは、最後に縮小した画像とフルサイズの画像で比べ直して「同じピク
    セル」から「似ている別の画像」までに分けます (別スレッドで行います)。

    左はグループの一覧です。種類ごとの見出しの下に並び、見出しの ▶ (またはダブ
    ルクリック) で開いたり折りたたんだりできます。最初は「完全に同じ」「大きさ
    違い」「同じピクセル」「保存し直し」を開き、「明るさ・色違い」「一部が違う」
    「似ている別の画像」は折りたたんでいます (ふつうは消さないものなので)。各
    グループには種類・枚数と、削除にしている枚数・容量が出ます。グループを選ぶ
    と、右にその画像が並び、大きさ・容量・形式・撮影日・先頭との一致度・場所・
    コメントの有無を比べられます。画像をクリックするとサムネイルウィンドウで表
    示します (動きは [設定 | 検索] で指定)。

    それぞれの画像の「残す」「削除」で選びます。「完全に同じ」「大きさ違い」の
    グループは、画素数が大きいもの (同じなら容量が大きいもの・古いもの) を「残
    す」に、他を「削除」にしてあります。ただし「大きさ違い」で、小さい画像を拡
    大しただけのコピーと分かったものは「拡大したコピーらしい」と表示し、残す候
    補から外します (グループを表示したあと別スレッドで調べ、分かったものから並
    べ直します。手で選んだ「残す」「削除」はそのままです)。「同じピクセル」
    「保存し直し」のグループは、残すのによさそうなものを先頭にして「残すおすす
    め」と理由を表示します (同じピクセルならファイルが大きい=メタデータが多い
    もの、保存し直しなら PNG など画素をそのまま保つ形式・画素数が多いもの・
    JPEG の画質が高いもの)。ただし表示するだけで、「削除」にはしていません。カー
    ドには JPEG の画質と、先頭とどう違うか (保存し直し・大きさ違い・明るさや色
    が違う・一部が違う・別の画像) が出ます。そのほかの種類のグループは全て「残
    す」です。右上の「ゴミ箱へ移動...」は、表示しているグループで削除にした画
    像だけを、確認のあとゴミ箱へ移動します (ゴミ箱から元に戻せます)。慎重に確
    かめられるよう、ゴミ箱へ移すのは 1 グループずつです。確認にはファイル名が
    出て、グループの全てを削除にしているときやコメントのある画像があるときはそ
    う表示します (全てを削除にしているときは「キャンセル」が既定)。移動のあと
    は次のグループを表示します。グループが 2 つ以上あるときは、下の「全部のグ
    ループの削除をゴミ箱へ...」で、全部のグループで削除にした画像をまとめて移
    動できます (全てを削除にしているグループは含めません)。

    移動の前に、削除する画像がもう一度、残す画像と同じかを比べます (「完全に同
    じ」のグループ)。調べたあとに変わったファイルは移動しません。削除する画像
    にコメント (タグ) かブックマークがあるときは、確認で「残す画像に移してゴミ
    箱へ移動」を選べます。残す画像にコメントがなければコメントごと移し、あれば
    タグだけを加えます (タグだけのコメントは消します)。ブックマークは残す画像
    になければ移します。「移さずにゴミ箱へ移動」では、コメントファイルはそのま
    ま残ります。

    ファイル名に意味があって残したいときは「ゴミ箱へ移してリンクを残す」です
    (「完全に同じ」のグループだけ)。ファイルはゴミ箱へ移り、同じ名前で残す画像
    へのリンクが置かれます。同じファイルシステムならハードリンク (容量を使わず、
    残す画像を移動しても切れません)、違えばシンボリックリンク (残す画像の絶対
    パス) です。コメント・タグ・ブックマークはその名前に付いたままです。リンク
    を作れないときは、ゴミ箱へも移しません。

    画像はこのウィンドウが自分で読み込むので、サムネイルビューで読み込んでいな
    い画像も表示します。探している間も操作でき、まず「完全に同じ」グループが出
    て、終わると全てのグループになります。アーカイブの中の画像は対象外です。探
    し方と分け方の詳細は「重複画像の探し方」を見て下さい。

索引から重複画像を探す
    索引の全部の画像から、中身がまったく同じファイル (「完全に同じ」) を探し、
    同じ結果のウィンドウで開きます。別のフォルダにある同じファイルも見つかりま
    す。索引が前もって調べておいた結果を使うので、画像を読まずにすぐ表示します。
    [設定 | 索引] の「同じファイルを探しておく」がオンのときに使えます。

    索引は、ほかの画像と同じ大きさ (バイト数) の画像だけを、ほかの処理のあとで
    読みます。先頭の 64 KB を比べ、同じものだけファイル全体を比べます。同じ名
    前で同じ大きさの画像 (別のフォルダに保存し直したもの) を先に調べるので、そ
    の分はすぐに見つかります。画像が多いと初回は何時間もかかることがあり、その
    間はステータスバーに「索引: 同じファイル n%」と出ます。途中でも、見つかっ
    た分だけを表示します。同じファイルへのハードリンクは 1 つとして数えます。
    大きさ違いや似ている画像は探しません (タブの画像から「重複画像を探す」で探
    します)。

    フォルダの下だけで探すときは、ディレクトリビューの右クリックの「下のフォル
    ダも含めて重複画像を探す...」、ある画像と同じファイルを探すときは、サムネ
    イルの右クリックの「同じファイルを探す」です。

壁紙設定
    選択している画像を、デスクトップの壁紙にします。「このデスクトップ」は、実
    行中のデスクトップ (環境変数 XDG_CURRENT_DESKTOP) に合うコマンドを使います。
    その下には、Xfce・GNOME・KDE Plasma などのデスクトップごとの項目があります。

    JPEG・PNG 以外の画像やアーカイブ内の画像は、PNG に変換して ~/.gimv/
    wallpaper/ に置いたものを壁紙にします。項目とコマンドは ~/.gimv/gimvrc の
    wallpaper_menu で変更できます。

    次の画像を表示します。

前へ [H]
    前の画像を表示します。

最初へ [K]
    最初の画像を表示します。

4.8. 動画

イメージウィンドウのみのメニューです。動画・音声を表示している時に使えます。

曲 (m4a・mp3・flac・ogg など) にアルバムアートが入っていれば、再生している間は
それを表示し、サムネイルにも使います (GStreamer プラグイン)。アルバムアートは
元の大きさで表示し (表示する場所より大きい時だけ縮めます)、画像と同じズームの
操作 (拡大・縮小・倍率・ウィンドウの大きさに合わせる) で大きさを変えられます。
アルバムアートの無い曲は、これまでどおり黒い画面で、サムネイルはありません。

再生 / 停止 / 一時停止 / 早送り / 巻戻し
    動画・音声の再生を操作します。

連続再生
    再生が終わると、次のファイルに移って再生します。初期状態は [設定 | 動画と
    音声] の連続再生に従います。

取り出し
    Xine プラグインで表示している時に使えます。停止中に、xine の入力プラグイン
    を選び、そのプラグインが再生できるもの (MRL) の一覧を表示対象にします。

音量・ミュート
    動画の下の操作バーの右端にあります (メニューにはありません)。スピーカーの
    ボタンで音を消したり戻したりし、その右のスライダーで音量を変えます (ホイー
    ルでも変えられます)。音を消している時にスライダーを動かすと、音が戻ります。
    音量とミュートはすべてのウィンドウで共通で、終了しても覚えています。
    GStreamer と MPlayer のプラグインで使えます (MPlayer では mplayer 自身の音
    量で、サウンドカードの音量は変えません)。

マニュアル
    マニュアルを表示します。

ドキュメント
    GImageView に付属するドキュメントを表示します。

GImageViewについて
    GImageView のバージョン、ライセンス、著作者、開発者などを表示します。

5. ツールバー
=============

ここではツールバーの各ボタンについて説明します。ツールバーの画像の番号は、説明
の項目の番号に対応しています。メニューバーに同等の機能があるボタンについては、
メニューバーの項目 (項4) も参照して下さい。

項目名は、ボタンにマウスカーソルを合わせた時に表示されるポップアップ内容に合わ
せています。

5.1. サムネイルウィンドウ

1 ファイルを開く
    [ファイル | 開く]と同じです。

2 設定
    [編集 | 設定]と同じです。

3 前のページへ
    前のタブ(1つ左)をアクティブにします。[タブ | 前のページ]と同じです。

4 次のページへ
    次のタブ(1つ右)をアクティブにします。[タブ | 次のページ]と同じです。

5 キャッシュ再読込
    [編集 | キャッシュ再読込]と同じです。

6 現ページのサムネイル作成をスキップ
    ディレクトリビューのマウスメニューから、サムネイルを再帰的に読み込みを行っ
    た時に、任意のディレクトリのサムネイル展開をスキップします。

    スキップされたタブ(ディレクトリ)は、ファイル名だけの表示となります。サムネ
    イルを作成していない時は使えません。

7 サムネイル作成を中止
    ディレクトリビューのマウスメニューから、[サムネイルを再帰的に読み込み]を行っ
    た時に、それを完全に中止します。サムネイルを作成していない時は使えません。

8 サムネイルサイズ
    サムネイルサイズを変更します。

    ここに任意の値を入れ、Enter した後に、「キャッシュ再読込」「全てのサムネイ
    ルを再作成」のどちらかを行うことによって、サムネイルが新しいサイズになりま
    す。

    サムネイルへの反映を、メニューからではなくショートカットキーで行う場合、
    ESC キーを押して、サイズ入力部からフォーカスを外してください。フォーカスを
    外さないと、その文字が入力されてしまいます。

    ここでの変更はアクティブになっていたタブにのみ有効です。

    キャッシュ再読込の方法については、Tips の「[リスト更新]・[キャッシュ再読込]
    ・[全てのサムネイルを再作成]の違いについて」を参照して下さい。

9 ディレクトリ入力欄
    アクティブになっているタブのパスが表示されます。

    この欄に、まだタブ表示されていないディレクトリを指定すると、そのディレクト
    リに画像があった場合のみ、新規にタブを開きます。また、ここではタブ補完が可
    能です。

10 サムネイルビューの表示モード
    アクティブになっているタブの、表示モードを変更します。ここでの指定はアクティ
    ブになっているタブにのみ有効です。指定できるのは以下の6つです。下の画像は、
    ウィンドウを広げた状態のサムネイルビューです。

    アルバム : サムネイルを横に並べ、その下にファイル名を表示します。

    アルバム2 : 小さなサムネイルとファイル名を、縦に並べて表示します。

    アルバム3 : サムネイルの横にファイル名・サイズ・更新日時を表示します。上か
    ら下へ並べ、下まで来ると次の列に続きます。

    詳細 : ファイル名・画像サイズ・サイズ・ファイルタイプなどを表にして表示し
    ます。表示するコラムは [設定 | サムネイルウィンドウ | サムネイルビュー |
    詳細ビュー] (項7.3.2.3) で指定します。

    詳細 + アイコン : 「詳細」の各行の先頭に、小さなサムネイルを表示します。

    詳細 + サムネイル : 「詳細」の各行の先頭に、サムネイルを表示します。

5.2. ディレクトリビュー

1 ホーム
    ディレクトリビューのカーソルをユーザのホームディレクトリ直下に変更すると同
    時に、全てのツリーを閉じます。サムネイルビューへの影響はありません。

2 上へ
    現在のトップディレクトリを、さらに1つ上に上げます。

    このコマンドは、マウスメニューのトップをここに変更を行った後に使うと便利で
    す。

3 更新
    ディレクトリビューを更新します。

    主に、コマンドラインからディレクトリ操作(新規作成・削除)を行った時に、それ
    らを反映させるために使用します。

4 ドットファイル表示/非表示
    ディレクトリビューへの、ドットディレクトリ表示 ON/OFF です。

5.3. イメージウィンドウ

ここに示す、画像のズーム(拡大縮小)、フィットなどの項目は、[設定 | イメージウィ
ンドウ] の自動的に画像のサイズにリサイズするの影響を受けます。設定によって、イ
メージウィンドウが自動リサイズされたりされなかったりします。

また、アスペクト比を保持する設定になっている場合、拡大縮小時に画像のアスペクト
比が維持されます。

1 ファイルを開く
    [ファイル | 開く]と同じです。

2 設定
    [編集 | 設定]と同じです。

3 前の画像
    [移動 | 前へ]と同じです。

4 次の画像
    [移動 | 次へ]と同じです。

5 等倍
    画像を本来の大きさ(100%)で表示します。

6 拡大
    画像の表示倍率を 5% 大きくします。

7 縮小
    画像の表示倍率を 5% 小さくします。

8 フィット
    イメージウィンドウの大きさに合わせて、画像を拡大縮小して表示します。

9 X軸スケール / Y軸スケール
    画像の表示倍率(%)を設定します。

    アスペクト比を保持する設定になっている場合は、X軸スケールだけが表示されま
    す。保持しない設定の場合は、その右に Y軸スケールも表示され、X軸・Y軸の倍率
    を別々に設定できます。

10 ズーム
    スケール部に入力した倍率に、画像をズーム(拡大縮小)して表示します。

11 見開き
    見開き表示の ON/OFF です (押し込まれている間が ON)。[表示 | 見開き | 見開
    き] と T キーと同じです。アイコンは今の並べ方で変わります (横に並べるだけ
    なら 2 枚並び、段があれば田の字)。右の ▼ で、見開きのメニュー (並べ方・右
    から左へ・1 ページ目は単独・1 ページずらす・並べ方を編集) を開きます。

    見開きの間は、ステータスバーの右に今のページが出ます。「見開き 2-3 / 8」は
    全 8 ページのうち 2・3 ページ目を並べていること、「見開き 6 (単独) / 8」は
    6 ページ目を 1 枚で表示していること (表紙・横長のページ・最後のページ) を
    表します。

12 画像を回転
    画像の向きを、0°・90°時計回り・180°・90°反時計回りから選びます。

13 ウィンドウの大きさを画像に合わせる
    表示している画像の大きさに、イメージウィンドウをリサイズします。[表示 | 画
    像の大きさに合わせる]と同じです。

14 全画面
    全画面表示にします。

    もう一度ボタンを押すことで、ウィンドウ表示に戻ります。

6. マウスメニュー
=================

ここでは、マウスボタンで表示されるメニュー (マウスメニュー) について説明します。
既定の設定では、右ボタンを押すと表示されます。割り当ては [設定] の各「マウスボ
タン」のページ (項7) で変更できます。メニューバーと同じ項目については、項4も参
照して下さい。

6.1. タブ

タブの部分で右クリックすると、現在表示しているタブのリストが表示されます。ここ
から任意のタブに移動することが可能です。

ディレクトリを再帰的に読み込んだ時など、大量のタブが生成された時に便利です。

6.2. サムネイルビュー

サムネイルビュー上でのマウスメニューです。複数選択されている場合、選択されてい
る全ての画像に対して有効です。

開く
    ディレクトリ・アーカイブの上で表示した場合にだけある項目です。そのディレク
    トリ・アーカイブのサムネイルを開きます。

新規ウィンドウで開く
    選択中の画像を、新規にイメージウィンドウを作成して開きます。複数選択されて
    いる場合、その数だけイメージウィンドウが作成されます。

共有ウィンドウで開く
    共有イメージウィンドウで開きます。共有イメージウィンドウを一つも作成してい
    ない場合、新規に作成します。既に共有イメージウィンドウが作成されている場合、
    そのウィンドウを再利用します。なお、このコマンドは複数選択時には使えません。

外部プログラムで開く
    選択中のファイルを登録した外部プログラムに渡します。外部プログラムのリスト
    は、項7.11を参照して下さい。

スクリプト
    選択中のファイルを登録したスクリプトに渡します。スクリプトの設定は、項
    7.11.1を参照して下さい。

サムネイル再作成
    選択中の画像のサムネイルを再作成します。

リストから削除
    このコマンドはコレクションタブのみ有効です。

    リストから削除します。ファイル自体が削除されるわけではありません。

印刷
    選択中の画像を印刷します。[ファイル | 印刷]と同じです。

プロパティ
    ファイルのプロパティを表示します。ファイルの権限や所有者などを変更できます。
    ファイル名と種類は選択してコピーでき、長いものは途中を省いて表示します (全
    体はツールチップ)。ファイル名の横の「コピー」でフルパスをクリップボードに
    入れます。

パスをコピー
    選択中の画像のフルパスをクリップボードに入れます (複数なら 1 行に 1 つ)。

EXIFデータを表示
    EXIF 対応で作成した場合にある項目です。画像の EXIF データを表示します。
    gexiv2 (Exiv2) を使って作成した場合は JPEG 以外 (TIFF・RAW・PNG・WebP・
    HEIF など) の EXIF も表示します (gexiv2 なしでは JPEG だけで、他の形式では
    この項目は出ません)。

コメントを編集
    選んだ画像のコメント (2.4) を編集します。

元のフォルダを開く
    画像のあるフォルダをサムネイルウィンドウで開き、その画像を選びます。索引や
    検索の結果のタブなど、いろいろなフォルダの画像が並ぶタブで便利です。

同じファイルを探す
    選んだ画像と中身がまったく同じファイルを、索引の全部の画像から探し、重複画
    像の結果のウィンドウで開きます (索引から重複画像を探す)。

タグを編集
    画像の索引が使える場合にある項目です。選んだ画像のタグを編集します (2.6)。

ブックマーク
    選んだ画像をブックマークし、メモの欄を出します (2.5)。

ファイル名変更 / ファイル名を UTF-8 に変換 / ディレクトリへコピー / ディレクト
リへ移動 / ディレクトリへリンク / ファイル削除
    [編集] メニューの同じ項目と同じです。

縮小して保存
    選択されている画像を小さくして、別のファイルとして保存します。元のファイル
    は変わりません。写真の容量を減らしたい時などに使います。

    「高さ」「幅」「長い辺」のどれを何 px 以下にするか (初期値は高さ 800 px)、
    JPEG と WebP の画質、名前に付ける文字 (初期値は「_resized」。big.jpg なら
    big_resized.jpg を元の画像と同じフォルダに) を選べます。同じ名前のファイル
    がある時は、名前に -1, -2 などを付けて上書きしません。EXIF の向きは画素に
    反映して保存します。

    撮影情報 (EXIF など) を残すか、残す時に位置情報 (GPS) を除くか、コメントや
    タグをコピーするかも選べます。指定より小さい画像はそのままコピーします。
    gdk-pixbuf で書き出せない形式の画像は JPEG で保存します。

    1 枚目の画像で、保存後の大きさと容量の見込みを表示します。保存は裏で行うの
    で、その間も操作できます。[中止] で残りを止められます。終わったら [保存し
    た画像を表示] で保存した画像を選んだ状態にできます。

画像を連結
    選択されている 2 枚以上の画像を 1 枚につなげて、別のファイルとして保存しま
    す。元の画像は変わりません。

     ・ 画像: つなげる順です。画像を選んで ↑ ↓ で順を変えられます。

     ・ 並べ方: 縦 (上から下へ)・横 (左から右へ)・格子状 (列の数を指定)。

     ・ 大きさ: 幅 (横に並べる時は高さ) を、小さいものに合わせる・大きいものに
        合わせる・そろえない。そろえない時は中央にそろえ、すき間は白にします。

     ・ 重なりを探す: 1 枚の写真を分けたもののように、つなぎ目で重なっている部
        分がある時に、前の画像の終わりと次の画像の始まりのいちばん似ている幅を
        探して重ねます (JPEG で少し違っていても見つけます)。白い部分のように模
        様のないところは重なりとみなしません。

     ・ 継ぎ目・重なり: つなぎ目ごとに、重なりの幅 (px) をスライダーや数字で直
        せます。「継ぎ目」で直すつなぎ目 (1 と 2、2 と 3、…) を選びます。横の
        (見つけた重なり: n px) は自動で見つけた値で、見つからなかった時は (重
        なりは見つかりませんでした) と出ます。

     ・ 継ぎ目の表示: 上の全体の見本では、つなぎ目を赤い破線で示します (選んで
        いるつなぎ目は濃く)。その下に、選んだつなぎ目のあたりを元に近い大きさ
        で表示します。縦に並べた時は、上が前の画像の終わり、下が次の画像の始ま
        りです。両端に赤い三角が 2 組あり、1 組目 (上・左) が次の画像の始まり、
        2 組目 (下・右) が前の画像の終わりで、その間が重なっている部分です (重
        なりが 0 なら 1 組)。1 組目から先は次の画像を表示しているので、1 組目
        の位置で絵に段差 (ずれ) がなく続いていれば合っています。

     ・ 差で表示: 重なっている帯 (2 組の三角の間) を 2 枚の画像の差で表示しま
        す。ぴったり合っていると帯が真っ黒になり、ずれていると物の輪郭が明るく
        浮き出ます。数字を 1 ずつ変えて、帯がいちばん暗くなるところを探すと合
        わせやすくなります。

     ・ 重なりが見つからない時: 空や白い背景のように模様のない部分だけで重なっ
        ていると、自動では見つけられないことがあります (どこでも同じように見え
        てしまうため)。その時は、両方の画像に写っている目印 (物の端や文字など)
        を手がかりに、数字で重なりを入れてください。

     ・ 画質 (JPEG・WebP、初期値 90)、1 枚目のファイルの情報 (EXIF など) を残
        すか、1 枚目のコメントと手動で付けたタグを引き継ぐか。

    1 枚目と同じフォルダに「名前_join.jpg」(形式は 1 枚目のまま。gdk-pixbuf が
    書けない形式は JPEG、MAG・Pi など gimv 独自のローダで読む形式は PNG) とし
    て保存します。MAG・Pi なども並べられます (表示と同じく実機の画素の形に伸ば
    した大きさで並べます)。PNG で保存するときは、元のファイルに書かれたコメン
    ト (MAG のコメントやユーザー名など) を PNG のコメントに引き継ぎます (ファ
    イルごとに違えば、それぞれのファイル名の下に)。[1 枚目のファイルの情報を残
    す] がオンなら、元のファイルのうち一番新しい更新日時を EXIF の DateTime に
    書きます (MAG・Pi などには EXIF がないため。索引の日付のタブでもその日付に
    並びます)。同じ名前があれば -1, -2 などを付けて、上書きはしません。EXIF の
    向きは画素に反映してから並べます。読み込み・重なりの検出・保存は別スレッド
    で行います。保存後、[保存した画像を表示] でサムネイルウィンドウの新しい画
    像を選べます。

6.3. ディレクトリビュー

ディレクトリビューには、ディレクトリのタブのほかに、画像の索引の日付・タグ・人
物のタブ (2.6、2.7) とブックマークのタブ (2.5) があります。上のアイコンでタブ
を切り替えます。右クリックのメニューはタブごとに違います。

6.3.1. ディレクトリのタブ

ディレクトリビューでは、ディレクトリの複数選択は出来ません。そのため、各コマン
ドの実行対象は、必然的にマウスカーソル下のディレクトリになります。

サムネイル読み込み
    カーソル下のディレクトリを読み込み、サムネイルビューに表示します。初めてサ
    ムネイル表示する場合は新規にタブが生成され、既に読み込まれている場合は、そ
    のタブがアクティブになります。

サムネイルを再帰的に読み込み
    カーソル下のディレクトリ以下を再帰的に読み込みます。ディレクトリごとにタブ
    が生成されます。

サムネイルを1タブ内に再帰読み込み
    カーソル下のディレクトリ以下を再帰的に読み込み、全ての画像を1つのタブに表
    示します。

下のフォルダも含めてタグを編集...
    カーソル下のディレクトリと、その下のディレクトリにある全ての画像のタグを編
    集します (2)。

下のフォルダも含めて重複画像を探す...
    カーソル下のディレクトリと、その下のディレクトリにある画像のうち、中身がまっ
    たく同じファイルがあるものを探します。同じファイルがほかのフォルダにあって
    も見つけます (索引から重複画像を探す)。

トップをここに変更
    カーソル下のディレクトリを、ディレクトリビューのトップにします。

ブックマーク...
    カーソル下のディレクトリをブックマークし、メモの欄を出します。ブックマーク
    のタブの「フォルダ・書庫」から開けます (2.5)。

ツリー更新
    ディレクトリビューを更新します。コマンドラインからディレクトリ操作(作成・
    移動・削除)を行った場合に、それらを反映させるために行います。

プロパティ
    ディレクトリのプロパティを表示します。権限や所有者などを変更できます。

ディレクトリ作成
    カーソル下のディレクトリ直下に、新規にディレクトリを生成します。

ディレクトリ名変更
    カーソル下のディレクトリ名を変更します。

ディレクトリ削除
    カーソル下のディレクトリを削除します。確認ダイアログの後、削除が実行されま
    す。

6.3.2. 日付のタブ

開く
    その年・月・日の画像を、サムネイルビューの結果のタブに表示します。年・月・
    日をクリックした時と同じです (2.6)。

新しいタブで開く
    結果のタブを使わずに、新しいタブに表示します。中ボタンのクリックでも同じで
    す。

6.3.3. タグのタブ

開く・新しいタブで開く
    日付のタブと同じです (6.3.2)。

名前を変更... (F2)
    手動で付けたタグの名前を変えます (2.6)。索引が自動で付けたタグ (フォルダ・
    カメラ・形など) では使えません。

このフォルダ名をタグにしない
    フォルダ名の自動タグの行で使えます。そのフォルダ名を [設定 | 索引 | 自動タ
    グ] の「タグにしないフォルダ名」に加え、タグから外します (2.6)。設定ウィン
    ドウを開いている間は使えません。

6.3.4. 人物のタブ

開く・新しいタブで開く
    日付のタブと同じです (6.3.2)。

顔を表示...
    その人 (名前のないグループや名前の候補も) の顔を、顔の一覧ウィンドウで開き
    ます。名前を付けたり、違う顔を外したりできます (2.7)。

名前を変更... (F2)
    人物のタグの名前を変えます (2.7)。人の名前は顔の一覧ウィンドウで変えます。

6.3.5. ブックマークのタブ

開く・新しいタブで開く
    クリックした項目 (全て・月・メモあり・メモなし) のブックマークの画像を表示
    します。使い方は日付のタブと同じです (6.3.2)。「フォルダ・書庫」の下のフォ
    ルダ・書庫は、自分のタブで開きます (開いていればそのタブへ)。「見つからな
    い」は見つからないブックマークのウィンドウを開きます (2.5)。

6.4. プレビュー

プレビュー上のマウスメニューには、ズーム・回転・アルファチャンネルを無視・透過
部分を市松模様で表示・動画・見開き・表示モード・スクロールバーを表示 [Shift +
S]・サムネイル作成 [Shift + T]・メモリバッファ [Ctrl + B]・画像を保存・印刷 が
あります。各項目は、イメージウィンドウのメニューの同じ項目 (項4.1〜項4.3、項
4.8) と同じです。

6.5. イメージビュー

イメージウィンドウのイメージビュー上のマウスメニューは、イメージウィンドウの
[表示] メニュー (項4.3) と同じです。

GTK 4 版では、次の項目を加えています (プレビューのマウスメニューにもあります)。

 ・ 回転 - 左右反転 (X) : 画像を左右反転します。回転と同じく、画像ごとに記憶し
    ます。

 ・ 画像をクリップボードにコピー (Shift+Ctrl+C) : 表示している画像をクリップボー
    ドにコピーします。

 ・ 切り抜き (C) : 表示している画像の一部を切り抜いて別のファイルに保存します
    (4.2)。

 ・ 顔の編集 (P) : 顔パネルを開き、画像に写っている顔に名前を付けます (2.7)。
    顔の認識が使える場合だけの項目です。

 ・ 元のフォルダを開く : 画像のあるフォルダをサムネイルウィンドウで開きます。

 ・ タグを編集 : 表示している画像のタグを編集します (2.6)。画像の索引が使える
    場合だけの項目です。

 ・ ブックマーク : 表示している画像をブックマークします (2.5)。

7. 設定
=======

設定ダイアログの各項目について説明します。

7.1. 一般

ファイルを開くウィンドウ
    コマンドラインからファイルを開いた時、また、ファイルオープンダイアログから
    「了解」を押した際の展開先ウィンドウを設定します。

    「〜ウィンドウで開く」のような指定が無い箇所では、ここの指定に従って展開先
    が決まります。

ディレクトリを開くウィンドウ
    コマンドラインからディレクトリを開いた時の展開先ウィンドウを設定します。

アーカイブを開くウィンドウ
    コマンドラインからアーカイブを開いた時の展開先ウィンドウを設定します。

ディレクトリを再帰的に取得する
    コマンドラインでディレクトリを引数に取った時、常に再帰的に取得するようにな
    ります。

    コマンドラインオプション、-dR と同義です。

シンボリックリンク先のディレクトリを読み込む / リンク先のディレクトリを読み込
まない
    再帰的に取得する際に、シンボリックリンク先のディレクトリも読み込むかどうか
    です。

スケーリング時の補間法
    画像をスケーリング(拡大縮小)する際の、補間方法を指定します。以下の4種類か
    ら指定できます。

     ・ Nearest : 最近傍法。最も速いが、画質は粗くなります。

     ・ Tiles : 拡大時は Nearest と同じ、縮小時は画素を平均します。

     ・ Bilinear : 双線形補間。速度と画質のバランスが良い方法です。

     ・ Hyperbolic : ハイパーボリック。最も高画質ですが、遅くなります。

配色
    ウィンドウの配色を、以下の3つから選びます。変更は「適用」または「了解」で
    すぐに反映されます。GTK 4 版で追加した項目です (初期値は「デスクトップのテー
    マ」)。

     ・ デスクトップのテーマ : デスクトップで選んだテーマ (GTK の gtk-theme-
        name。X11 では XSETTINGS の Net/ThemeName) で表示します。GTK 4 は gtk-
        4.0 ディレクトリのないテーマ (GTK 2/3 用のテーマ) を読めず、明るい
        Adwaita で表示します。そのようなテーマの名前に「dark」が含まれる場合
        (Greybird-dark など) は、暗い Adwaita で表示します。

     ・ ライト : 明るい配色で表示します。テーマの名前が「-dark」で終わる場合は、
        それを除いた名前のテーマを使います。そのテーマを GTK 4 が読めない場合
        は Adwaita を使います。

     ・ ダーク : 暗い配色で表示します。テーマに暗い版 (gtk-dark.css) がない場
        合は、暗い Adwaita を使います。

    環境変数 GTK_THEME が設定されている場合は、GTK はそのテーマを使い、この項
    目は働きません。黒い線だけで描かれた GImageView 独自のアイコン (ズーム、ドッ
    トファイル表示/非表示など) は、暗い配色では明るい線で表示されます。

ボタンにデスクトップのアイコンテーマのアイコンを使う
    ツールバーなどのボタンに、デスクトップのアイコンテーマ (Adwaita、Papirus
    など) のアイコンを使います。テーマに対応するアイコンがないボタンや、ディレ
    クトリツリーのアイコンは GImageView 独自のものです。変更後に開いたウィンド
    ウから反映されます。GTK 4 版で追加した項目です (初期値は ON)。

    独自のアイコンを使いたい場合は、~/.gimv/icons/<名前>/ にアイコン名のファイ
    ル (back.png、zoom_in.svg、refresh.xpm など。PNG、SVG、XPM が使えます) を
    置き、~/.gimv/gimvrc の iconset= にその名前を書いて下さい。置いたアイコン
    はテーマのアイコンより優先されます。

スクロールバーを常に表示する
    一覧などのスクロールバーを常に表示します。OFF にすると、GTK 4 の標準どおり、
    ポインタを近づけたときだけ内容に重ねて表示します。GTK 4 版で追加した項目で
    す (初期値は ON)。

サムネイルウィンドウを開く
    GImageView を起動した時、常にサムネイルウィンドウを開くかどうか、です。

ディレクトリを無視する
    引数にディレクトリを与えられた時、それを無視するようになります。

警告を表示しない
    コマンドラインから起動した時に表示される警告メッセージを抑制します。

スプラッシュウィンドウを表示する
    起動時にスプラッシュウィンドウ(ロゴ画像)を表示するかどうか、です。GTK 4 版
    で追加した項目です。

7.1.1. フィルタ

ファイルタイプ
    拡張子とファイルタイプ (MIME タイプ) の対応の一覧です。「状態」が「無効」
    の拡張子のファイルは読み込みません。

    一覧の下の欄で拡張子とファイルタイプを入力し、「追加」で新しい対応を登録し
    ます。登録済みの対応は、選択して「変更」「削除」できます。「無効」にチェッ
    クを入れると、その拡張子を無効にします。「システム定義」の対応は削除できま
    せん。

ドットファイルを読み込む
    .で始まる画像ファイルやディレクトリを開くかどうか、です。なお、ディレクト
    リビューに関しては専用の設定 (項7.3.3) がありますので、ここの設定に従いま
    せん。

拡張子を無視する
    ファイルの拡張子による判別を行わず、全てのファイルを読み込みの対象にします。

7.1.2. キャラクターセット

ロカールのキャラクターセット
    画像につけるコメントのロカールキャラクターセットの定義です。

内部キャラクターセット
    GImageView で使用する、内部キャラクターセットの定義です。

自動検出する言語
    GImageView が自動検出する言語の設定です。

ファイル名のキャラクターセット
    ファイル名を表示する際などに用いられる、キャラクターセットです。「変換しな
    い」「ロカール」「自動検出」「任意」から選びます。「任意」の場合は、右の欄
    でキャラクターセットを指定します。

    この設定で変換できない名前 (UTF-8 のシステムで、MS-DOS 時代の Shift_JIS や
    UNIX の EUC-JP で付けられた名前など) は、「自動検出する言語」が日本語か、
    言語の設定 (LANG など) が日本語のとき、Shift_JIS・EUC-JP・ISO-2022-JP のう
    ちもっとも日本語らしく読めるもので表示します。どれとも判らない名前は、読め
    ないバイトを URL のように %XX (16 進数) で表示します (例: caf%E9.jpg)。表
    示が変わるだけで、ファイルはもとの名前のまま開けます。書庫の中のファイル名
    と、画像のファイル自体に書かれたコメントも同じように表示します。

    文字コードを推定して表示した名前は、一覧で斜体になります (詳細表示とアルバ
    ム表示)。マウスを乗せると、推定した文字コードともとのバイト列をツールチッ
    プで表示し、選ぶとステータスバーにも「⚠ ファイル名が UTF-8 ではありません」
    と表示します。名前を UTF-8 に直すには [編集 | ファイル名を UTF-8 に変換]
    (4.2) を使います。

7.2. イメージウィンドウ

終了時にウィンドウの状態を保存する
    終了時のウィンドウサイズ、各バーの表示/非表示などを保存し、次回起動時に反
    映させるようになります。このオプションが OFF の場合、「ウィンドウの初期サ
    イズ」と「表示/非表示」の各項目で初期状態を設定します。

ウィンドウの初期サイズ
    イメージウィンドウを生成した時の、初期サイズ (幅・高さ) を決めます。

自動的に画像のサイズにリサイズする
    イメージウィンドウを生成した時、自動的に展開画像のイメージサイズにウィンド
    ウをリサイズするようになります。

    GImageViewの詳しい挙動を書きますと、まず上の「ウィンドウの初期サイズ」のサ
    イズでイメージウィンドウが生成されます。その後、ここのオプションが有効になっ
    ていれば、展開した画像のサイズにイメージウィンドウが自動的にリサイズします。
    このように動作が2段階になりますので、処理時間は増えることになります。

ファイルごとに別のウィンドウを開く
    毎回、ファイルごとに新規イメージウィンドウを作ります。展開したファイルの数
    だけイメージウィンドウが出来ることになります。また、それらのウィンドウは共
    有されることはありません。

共有ウィンドウで開くときは、前面に出す
    サムネイル右クリックメニュー、共有ウィンドウで開くから、共有イメージウィン
    ドウを生成した場合に、ウィンドウを最前面に出すようにします。

メニューバー / ツールバー / スライドショープレーヤ / ステータスバー / スクロー
ルバー
    イメージウィンドウを開いた時に各種バーを表示するかどうかです。[設定 | イメー
    ジウィンドウ] の終了時にウィンドウの状態を保存するが OFF の場合に指定でき
    ます。

    スクロールバーは、画像がウィンドウからはみ出す向きにだけ表示されます。この
    項目を OFF にすると、はみ出す場合も表示しません。

プレーヤツールバー
    動画・音声の再生用ツールバーの表示方法です。「表示」「非表示」のほか、「自
    動」では動画・音声を表示している時だけ表示します。

背景色を指定
    チェックを入れると、画像の背景を「色選択」で選んだ色で塗ります。

画像の透過部分を市松模様で表示する
    透過のある画像の背景を、灰色の市松模様で表示します。GTK 4 版で追加した項目
    です (初期値は ON)。

フルスクリーンの背景色を指定
    チェックを入れると、全画面表示の時の背景を「色選択」で選んだ色で塗ります。

7.2.1. 画像

イメージウィンドウで画像を表示する時の設定です。

ズーム
    画像を表示する時の大きさを、以下から選びます。

     ・ デフォルトの画像拡大率 : 下の「デフォルトの画像拡大率」で表示します。

     ・ 変更しない : 直前に表示していた画像の拡大率のまま表示します。

     ・ ウィンドウの大きさに合わせる : ウィンドウの大きさに合わせて拡大縮小し
        ます。

     ・ ウィンドウの大きさに合わせる(拡大しない) : ウィンドウより大きい画像だ
        けを縮小します (初期値)。

     ・ 画像をフレーム幅に合わせる / 画像をフレーム高さに合わせる : 幅または高
        さをウィンドウに合わせます。

回転
    画像を表示する時の向きです。0°、90°反時計回り、180°、90°時計回りのほか、
    「変更しない」(直前の画像の向きのまま) を選べます。EXIF 対応で作成した場合
    は、「EXIFデータに応じる」も選べます。

画像ごとに回転・左右反転を覚える (コメントと一緒に保存)
    画像を回転・左右反転すると、その向きをコメントと同じ場所に保存し、次にその
    画像を開いた時に同じ向きで表示します。GTK 4 版で追加した項目です (初期値は
    ON)。

アスペクト比を保持
    画像を拡大縮小した時、アスペクト比(画像の縦横比率)を保持するようになります。

デフォルトの画像拡大率
    デフォルトの画像拡大率を指定します。「ズーム」が「デフォルトの画像拡大率」
    か「変更しない」の場合に指定できます。

元の画像をメモリに保持するか否か
    表示した画像をメモリ上に保持するようになります。具体的な効果は、Tipsの「イ
    メージビューの描画を速くする」を参照して下さい。

7.2.2. マウスボタン

マウスボタンの割り当てを設定します。ボタン (左・中・右、ホイールの上下、左のダ
ブルクリック、サイドボタンの「戻る」(ボタン 8) と「進む」(ボタン 9)) ごとに、
修飾キー (普通・Shift・Control・Mod1 (Alt)) の組み合わせについて、機能と、ボタ
ンを押した時 (プレス) と離した時 (リリース) のどちらで実行するかを指定して下さ
い。ボタン 8・9 の初期値は「なし」です。

「ルーペ (押している間)」: ボタンを押している間、カーソルの位置に画像を拡大し
た四角 (ルーペ) を重ねて出し、カーソルに付いて動きます。離すと消えます。拡大は
画像そのものに対してで (100% で画像の 1 画素が画面の 1 画素)、ウィンドウに合わ
せて縮小して表示している写真でも細部を見られます。押したままホイールを回すと
100%・200%・400%・800%・1600% と変わり、最後の倍率を覚えておきます (表示より小
さい倍率にはなりません)。初期値は Control と左ボタン (プレス) です。GTK 4 版で
追加した機能です。

7.3. サムネイルウィンドウ

終了時にウィンドウの状態を保存する
    終了時のウィンドウサイズ、レイアウト、各部の表示/非表示などを保存し、次回
    起動時に反映させるようになります。このオプションが OFF の場合、「幅」「高
    さ」「レイアウト」と「表示/非表示」の各項目で初期状態を設定します。

幅 / 高さ
    サムネイルウィンドウを生成した時の、初期サイズを決めます。

レイアウト
    サムネイルウィンドウ内の各ビュー(ディレクトリ・サムネイル・プレビュー)の配
    置を、レイアウト0〜4、カスタムから選びます。メニューの表示 | レイアウトと
    同じものです。

表示/非表示
    サムネイルウィンドウを開いた時に、ディレクトリビュー・プレビュー・プレビュー
    タブ・メニューバー・ツールバー・ステータスバー・タブを表示するかどうかです。

プレーヤツールバー
    プレビューの動画・音声用ツールバーの表示方法です。「自動」では動画・音声を
    表示している時だけ表示します。

サムネイルを開くときにウィンドウを前面に出す
    サムネイル展開終了時にウィンドウを前面に出すかどうか、です。

    これは「ディレクトリの再帰読み込み」を行った時も有効です。この場合、各ディ
    レクトリのサムネイル展開が終了するたびにサムネイルウィンドウが最前面に出て
    くるようになります。

ツールバーのスタイル
    ツールバーのボタンを、アイコン・テキスト・その両方のどれで表示するかを選び
    ます。

ローディングの詳細情報を表示
    サムネイルの読み込み中に、プログレスバーに「読み込んだ数/全体の数」と、読
    み込んでいるファイル名を表示します。

7.3.1. タブ

タブの位置
    ウィンドウのタブ位置を指定します。

    ただし、[設定 | サムネイルウィンドウ] の終了時にウィンドウの状態を保存する
    が OFF 状態でないと、本項目は有効になりません。

自動的に新規タブに移動する
    新しくタブが生成された時、そこに移動するようになります。

クローズボタンを表示
    表示しているタブの右端にクローズボタンが表示されるようになります。他のタブ
    は、中ボタンでタブをクリックしても閉じられます (この設定に関わらず)。

フルパスを表示する
    タブにディレクトリ (アーカイブ) のパスを全て表示します。デフォルトでは OFF
    で、ディレクトリ名 (アーカイブのファイル名) だけを表示します。どちらの場合
    も、マウスを合わせるとパス全体が表示されます。
    タブがたくさんあって狭い時は、表示しているタブには名前が読める幅を取り、他
    のタブは数文字に縮めます。入りきらない時はタブの両端の矢印でスクロールでき
    ます。

画像が存在しないディレクトリを指定した場合もタブを開く
    画像が存在しないディレクトリを指定した場合もタブを開くようになります。

7.3.2. サムネイルビュー

表示/非表示
    サムネイルビュー内に、ディレクトリ、アーカイブを表示するかどうかです (初期
    値はディレクトリが OFF、アーカイブが ON)。

    表示したディレクトリとアーカイブのサムネイルは、中の最初の画像 (名前順、数
    字は数の大きさで) を表紙として表示します。表紙は画面に見えているものだけを
    別スレッドで探し、サムネイルのキャッシュを作る設定ならキャッシュに保存して
    次からはそれを使います。アーカイブは、zip・cbz・lzh・圧縮していない tar は
    中の一覧から名前順の最初の画像を取り出します。rar・7z・圧縮した tar は全体
    を展開しないと一覧できない (ソリッドのことがある) ので、先頭から読みながら
    それまでで名前順の最初の画像を表紙にし、3 秒か展開した量 256 MB を超えたら
    そこまでで決めます (大きなソリッドの書庫では、最初の方の画像になることがあ
    ります)。表紙の見つからなかったものはアイコンのままにし、その回は探し直し
    ません。「..」 (親ディレクトリ) はアイコンのままです。

デフォルト表示モード
    サムネイルウィンドウのデフォルト表示モードを指定します。[設定 | サムネイル
    ウィンドウ] の終了時にウィンドウの状態を保存するが OFF の場合に指定できま
    す。

サムネイルサイズ
    デフォルトのサムネイルサイズを指定します。[設定 | サムネイルウィンドウ] の
    終了時にウィンドウの状態を保存するが OFF の場合に指定できます。

7.3.2.1. マウスボタン

マウスボタンの割り当てを設定します。ボタン (左・中・右、ホイールの上下、左のダ

ンを押した時 (プレス) と離した時 (リリース) のどちらで実行するかを指定して下さ

表示モードが「アルバム」「アルバム2」「アルバム3」の場合の設定です。各表示モー
ドの画面は、項5.1 のサムネイルビューの表示モードを参照して下さい。

行間の空白
    サムネイルの行間の空白幅を指定します。

列間の空白
    サムネイルの列間の空白幅を指定します。

7.3.2.3. 詳細ビュー

表示モードが「詳細」「詳細 + アイコン」「詳細 + サムネイル」の場合に表示するコ
ラムを指定します。右側の「表示するコラム」にある項目が表示項目です。「追加」
「削除」で項目を移し、「上へ」「下へ」で順番を変えます。また、「コラムタイトル
を表示する」でコラムタイトルの表示/非表示も設定できます。

GTK 4 版では、コメントの「題名」と「コメント」(メモ欄の 1 行目) の項目を追加し
ました。表示するには、これらを右側のペインに移して下さい。コメントを保存・削除
すると、表示中の一覧にすぐ反映されます。なお、アルバム表示では、コメントのある
画像にマウスを合わせると、題名とメモ欄の内容がツールチップで表示されます。

「撮影日」の項目は、画像の索引の撮影日 (コメントの「日付」、EXIF、ファイル名の
日付、更新日時の順) を表示します。索引の外の画像は更新日時です。コラムタイトル
をクリックすると撮影日の順に並べ、もう一度クリックすると逆順 (新しい順) になり
ます ([表示 | ファイルソート | 撮影日] と同じです)。「ブックマーク」の項目は、
ブックマークを付けた画像に黄色い★を表示する狭いコラムです (見出しも★)。表示す
る項目の一番上に置くと、サムネイル (アイコン) より左に並びます。見出しをクリッ
クするとブックマークを付けた画像を先に並べ、もう一度クリックすると逆になります
([表示 | ファイルソート | ブックマーク] と同じです)。

並べ替えに使っているコラムのタイトルには矢印 (昇順は上向き、逆順は下向き) が付
きます。メニューで並べ替えた場合も同じです。「画像サイズ」のタイトルをクリック
すると面積の順に並べます。並べ替えのないコラム (キャッシュタイプ、ユーザー、題
名など) のタイトルはクリックできません。

    「ドットファイルを表示」するオプションが OFF の時でも、ディレクトリビュー

7.4. 動画と音声

動画と音声用のデフォルト表示モード
    動画・音声ファイルを再生するプラグイン (GStreamer・MPlayer・Xine のうち、
    組み込まれているもの) を選びます。

動画・音声の再生が終わったら次のファイルを再生する (連続再生)
    再生が終わると、次のファイルに移って再生します。GTK 4 版で追加した項目です
    (初期値は OFF)。

動画・音声の再生中は、マウスでの次/前の画像・拡大縮小・回転・スクロールを無効
にする
    再生中の誤操作を防ぎます。マウスボタンに割り当てたポップアップメニューは使
    えます。GTK 4 版で追加した項目です (初期値は OFF)。

その下の「GStreamer」「MPlayer」「Xine」の各ページでは、それぞれのプラグインで
動画のサムネイルを作成するかどうかと、サムネイルにする位置 (ストリームの位置)
を指定します。MPlayer・Xine のページでは、使用するドライバも指定します。ページ
は、組み込まれているプラグインの分だけ表示されます。

7.6. サムネイルキャッシュ

キャッシュについて、読込、書込のファイル形式を指定します。

キャッシュ読込
    右側の「使用するキャッシュタイプ」にある形式のキャッシュを、上から順に探し
    て読み込みます。「追加」「削除」で項目を移し、「上へ」「下へ」で順番を変え
    ます。

キャッシュ書込
    サムネイルを作成した時に保存するキャッシュの形式を選びます。「設定」で、選
    んだ形式の設定を変更できます。

freedesktop.org
    GTK 4 版で追加したキャッシュ形式です。freedesktop.org の Thumbnail
    Managing Standard に従い、~/.cache/thumbnails に他のプログラム (Nautilus、
    Thunar など) と共有するサムネイルを読み書きします。画像が更新されると、古
    いサムネイルは使いません。サムネイルは EXIF の向きどおりに回して保存します。

サムネイルの作成
    「JPEG に埋め込まれた縮小画像 (EXIF) が十分な大きさならそれを使う」を ON
    にすると、JPEG のサムネイルをファイルの先頭だけ読んで速く作ります。OFF に
    すると、常に画像そのものから作ります (縮小画像を更新しないソフトで編集した
    画像でも、正しいサムネイルになります)。GTK 4 版で追加した項目です (初期値
    は ON)。

    変更・削除ができます。

キャラクターセット
    コメントファイルのキャラクターセットを指定します。

7.8. 索引

画像の索引 (2.6) と顔の認識 (2.7) の設定です。SQLite を使ってビルドした場合だ
けのページです。変更は「適用」または「了解」の後、索引プロセスを起動し直して反
映します。

索引
    「画像の索引を作り、日付で見られるようにする」と「索引を作るディレクトリ」
    です。指定したディレクトリの下の画像が索引の対象になります。「同じファイル
    を探しておく」がオンのときは、ほかの処理のあとで、ほかの画像と同じ大きさの
    画像を読み、同じファイルを探しておきます (索引から重複画像を探す)。初回は
    何時間もかかることがあり、途中で終了しても次の起動で続きから進みます。

索引 | 新しい画像
    新しい画像をデスクトップに通知するかどうか、まとめて通知するまでの待ち時間、
    通知の最小間隔、通知の表示時間、通知しないフォルダです。通知の出る場所は、
    デスクトップの通知の設定によります。

索引 | 自動タグ
    自動で付けるタグの種類 (フォルダ名、カメラ、形、他のプログラムが付けたキー
    ワード) と、タグにしないフォルダ名 (「*」は任意の文字列、「?」は任意の 1
    文字。大文字と小文字は区別しません) です。カメラ・形・キーワードをオンにす
    ると全ての画像を読み直すので、画像が多いと時間がかかります。

索引 | 顔
    顔を認識するフォルダ (索引を作るディレクトリの中) と、モデルファイルの場所
    です。モデルファイルが見つからない場合は、置き場所と入手先 (URL) を表示し
    ます。顔の認識が使える場合だけの項目です。

    モデルファイルは次の 2 つです。~/.local/share/gimageview/models に置きます
    (名前はこのまま。同じ場所にある量子化版の「_int8」「_int8bq」は使いません)。

     ・ face_detection_yunet_2023mar.onnx (顔を探す、約 230 KB)

     ・ face_recognition_sface_2021dec.onnx (顔を比べる、約 39 MB)

    入手先は OpenCV Zoo です。

     ・ GitHub (設定のページに出る URL):
        https://github.com/opencv/opencv_zoo/raw/main/models/
        face_detection_yunet/face_detection_yunet_2023mar.onnx
        https://github.com/opencv/opencv_zoo/raw/main/models/
        face_recognition_sface/face_recognition_sface_2021dec.onnx

     ・ Hugging Face (GitHub から取れない時。OpenCV Zoo は Hugging Face に移っ
        たと GitHub の README にあります):
        https://huggingface.co/opencv/face_detection_yunet/resolve/main/
        face_detection_yunet_2023mar.onnx
        https://huggingface.co/opencv/face_recognition_sface/resolve/main/
        face_recognition_sface_2021dec.onnx

    GImageView はモデルファイルの中身を確かめ (SHA-256)、ダウンロードが壊れて
    いたり、同じ名前で中身の違うファイル (別の版) だったりすると使いません。そ
    の時はこのページとステータスバーのツールチップに、入手し直すファイルと URL
    を表示します。顔の特徴をどのモデルで計算したかは索引に記録しています。新し
    い版の GImageView でモデルが変わった時は、見つけてある顔の場所で特徴を計算
    し直します (顔・名前・「この人ではない」はそのままで、ステータスバーに進み
    具合が出ます。読めなくなった画像の顔は、読めるようになった時に探し直します)
    。

索引 | 行方不明の画像
    コメント (タグ) の付いた画像が見つからなくなったときのログを、いくつ残すか
    です (0 は作りません)。

9. GImageView FAQ
=================

9.1. 入手方法・インストール・起動

configure がないのだけど
    GTK 4 版は configure (autoconf / automake) ではなく Meson でビルドします。
    手順は インストール を見て下さい。

GImageView のサムネイルウィンドウ単体で起動したい
      $ gimv -w

    として起動してください。[編集・設定]・[一般 | 起動時 | サムネイルウィンド
    ウを開く]にチェックが入っている場合、-w の引数はいりません。

      $ gimv

    だけで起動します。この後は、どこか適当なディレクトリ・ファイルを開くことで
    普通に動きます。

    ランチャに登録する場合、gimv と単体で指定してやれば OK です。

9.2. 操作方法・設定

定義されているキーバインドを変更したい
    [編集 | キーボードショートカット...] で変更できます。行のキーをクリックし
    て新しいキーを押すと、すぐに有効になり保存されます (4)。

    ファイルを直接編集することもできます。~/.gimv/keyconf は右ボタンメニュー・
    補完・ナビゲーター・表示形式のキーで、次回起動時から有効になります。

    メニューのショートカットキーは ~/.gimv/keyaccelrc で変更できます。終了時に
    全メニュー項目の行が書き出されるので、変更したい行の先頭の「;」を消して、
    キーを書き換えて下さい。例えば、サムネイルウィンドウの [ファイル | 開く]
    (標準は Ctrl + F) を F3 にするには、次のようにします。次回起動時から有効に
    なります。

      (gtk_accel_path "<ThumbWinMainMenu>/File/Open..." "F3")

    キーバインドを変更した場合、どういう挙動になるかは当人しか分かりません。at
    your own risk でお願いします。

9.3. サムネイルウィンドウ

ステータスバーに表示されているものは?
    左から、フォーカスのある画像のフルパス (ホームディレクトリの下は「~」で表
    示)、その画像がタブの中で何枚目か ("10 / 16 枚目") とファイルサイズです。
    複数の画像を選んでいるときは、選んだ枚数と合計サイズ ("5 枚選択 812 kB")
    を表示します。右端は画像の索引の状態 ("索引: 28 枚" など。詳しくはツールチッ
    プ) と「お知らせ」ボタンです (2.3)。

以前の版のファイル数・合計サイズ・タブの番号はどこに?
    GTK 4 版では、ステータスバーには開いている画像の情報だけを表示し、全部のタ
    ブのファイル数・合計サイズ・タブの番号 ("**/** files"、"**/** kB"、"**/**
    page") は表示しなくなりました。タブの中の画像の枚数は、画像の位置の表示
    ("10 / 16 枚目") の後ろの数でわかります。開いているタブの一覧は、タブの部
    分を右クリックすると表示されます。

ツールバーの右にある、入力エントリはどうやって使うの?
    絶対パスでいろいろ指定してみて下さい。ディレクトリツリーが(表示させていれ
    ばですが……)面白いことになると思います。

    非常に説明し辛いのですが、ここは新規(ないしは既存の)タブをコマンドライン的
    に指定する所です。ディレクトリビューを表示させてない場合でも、ファイルオー
    プンダイアログに頼ることなく、新規にタブを開く、既存のタブに移動することが
    可能です。

    この入力エントリでは、TAB キーによる補完が聞きます。bash や tcsh や zsh と
    同じ気分でばんばん TAB してやって下さい。候補が1つしかない場合、勝手に補完
    されます。候補が多数ある場合、入力エントリ下に候補が一覧表示されます。この
    入力エントリでは、"~/"というユーザホームディレクトリの短絡指定は無視されま
    す。必ず、絶対パスから指定して下さい。

    また、ここで個別のファイルを指定することは出来ません。それらに対する入力補
    完もききません。単一の画像を別ウィンドウで開きたい場合、一旦そのディレクト
    リをサムネイル表示させ、そこから中ボタンクリックや左ダブルクリックなどで開
    いて下さい。

    入力エントリにフォーカスが移った場合、そこからフォーカスを戻す(キーボード
    ショートカットを有効にする)には、以下の方法を取って下さい。

     1. ディレクトリビュー上で、どっかのディレクトリを左クリックして"選択"する。

     2. サムネイルビューで、何らかの画像をクリック(選択・選択解除)する。

     3. タブをクリックし、別のタブに移動する。

     4. プレビューウィンドウで左クリック(ないしは、Shift+左クリック)して表示を
        変える。

     5. Esc キーを押す。

    GImageView から別のウィンドウに(たとえば rxvt とか)にフォーカスを移動させ
    ても、GImageView 上のフォーカスは切り替わりません。上述したような、何らか
    の操作を行わない限り、入力エントリからフォーカスが移ることはありませんので、
    注意して下さい。

9.4. タブ

現在開いているタブの一覧を表示するには
    タブの部分を右クリックしてください。現在開かれているタブの一覧が表示されま
    す。任意のタブに移動することもできます。

タブのフルパス表示を止める
    [設定 | サムネイルウィンドウ | タブ] の "フルパスを表示(show full path)"の
    チェックを外してください。ディレクトリ名だけがタブに表示されるようになりま
    す。この時、タブのフルパスは、タブにマウスポインタを置くとツールチップで表
    示されます。

コレクションタブとは
    [ファイル | 新規コレクション] から作ることが出来ます。または、どこのタブで
    もいいので画像を選択し、適当に DnD してください。

    DnD メニューが現れましたね?

    そこで、[新規タブで開く] を選んでください。ドラッグしていた画像(複数の場合
    はそれら全部)が、新しいタブ(コレクションと名前が付いています)で開かれます。

    作ったコレクションタブに新しい画像を追加するには、以下の方法があります。

     1. コレクションタブのタブの所に、DnDする

     2. コレクションタブ内のサムネイルビューに DnD する (この場合、別のアプリ
        ケーションか、2つめ以降のgimvになります)

     3. コレクションページを開いた状態で、ファイルオープンダイアログ(ツールバー
        の左端のボタン)からファイル を選択し、"選択したファイルのサムネイル"

    なお、コレクションページへの DnD は、DnD メニューが表示されずに、いきなり
    ファイルが追加されます。

    コレクションした後は、任意ディレクトリに移動するなり、コピーするなりしましょ
    う。コレクションされた画像はそれでひとまとまり、とされます。Ctrl クリック
    で任意の画像をクリックして行くよりも、コレクションタブに一旦集め、それらに
    対してファイル操作を行った方が、画像の整理効率が良くなると思います。

9.5. ディレクトリビュー

コンソールからディレクトリを増やした時に、ツリーに反映させる方法
    ツリービューから、増やした親ディレクトリで [ツリー更新] を行えば反映されま
    す。なお、ツリービュー右クリックメニューから [ディレクトリ作成] を行えば、
    即座に反映されるため、こちらを使ってディレクトリを増やした方が簡単です。

ディレクトリビュー右クリックメニュー、"サムネイルを再帰的に読み込み"について
    そのディレクトリ以下を再帰的に読み込みます。

    そのディレクトリ以下を全て展開し、各ディレクトリごとにサムネイルタブを作る、
    ということです。ある一定の場所だけ展開する時に非常に便利です。ツリーもきち
    んと展開されます。

    上位のディレクトリで(~/直下など)で再起的読み込みしてしまい、ディレクトリの
    読み込みが止まらなくなってしまった場合、ツールバーのストップボタンで止める
    か、スキップボタンでそのディレクトリを飛ばしてください。

ディレクトリビューにある「.」「..」とは
    例を挙げて説明します。

      /home/〜
          + cg
             + .
             + ..
             + desktop
             + favorite
             |    + .   (1)
             |    + ..  (2)
             |    + web
             |    + download
             + tmp

    などとなっていたとしましょう。ここで、(1)の「.」をダブルクリックすると、

      /home/〜
         + web
         + download

    と、そのディレクトリがルートディレクトリになります。これは、ディレクトリビュ
    ーの右クリックメニュー、[トップをここに変更] と同じ意味です。

    そして(2)の「..」をダブルクリックしますと、

      /home/〜
         + desktop
         + favorite
         |    + web
         |    + dl
         + tmp

    と、その親ディレクトリがルートになります。

タブウィンドウから、ディレクトリビューへの DnD で、ツリーの自動展開・ビューの
上下方向自動スクロールを行うには
    この設定 ([オートスクロール] ・ [ツリーを自動的に展開する]) は GTK+ 1.2 版
    だけのもので、GTK+ 2 版以降 (GTK 4 版を含む) にはありません。ドロップ先の
    ディレクトリが閉じている場合は、あらかじめ展開しておいて下さい。

9.6. サムネイルビュー

起動時、新規タブ時のリストビュー方法を固定する
    [設定 | サムネイルウィンドウ | サムネイルビュー | デフォルト表示モード]に
    て指定できます。ただし、ここを有効にするには、「終了時にウィンドウ状態を保
    存する」がノンチェック(保存しない)であることが必要です。

サムネイルが妙に汚いです

    えず、サ
    ムネイル再作成を実行してください。

画像の一括選択・解除

10. Tips
========

イメージビューの描画を速くする
    [設定 | イメージウィンドウ | 画像 | 元の画像をメモリに保持する] にチェック
    を入れる。開いているイメージウィンドウだけなら、[ファイル | メモリバッファ]
    (Ctrl + B) で切り替えられます。

    GImageView は、画像を表示し終えると元の画像 (読み込んだ画素のデータ) を捨
    てます。そのため、拡大率を変えたり回転・反転したりすると、元の画像をファイ
    ルから読み込み直します。元の画像をメモリに保持しておけば読み込み直さずに済
    むので、大きな画像ほど速くなります。

    最初に画像を開く時は、どの設定でもファイルから読み込むので、このオプション
    は関係ありません。保持すると、画像 1 枚につき 幅 × 高さ × 3〜4 バイト
    (1,200 万画素の写真なら 40 MB ほど) のメモリを余分に使います。このためデフォ
    ルト設定は OFF です。なお、アニメーション・動画・音声は、設定に関わらず保
    持します。

サムネイルサイズを一時的に変更する
    ツールバーのサムネイルサイズの値を変え (数字を入力した時は Enter を押しま
    す)、[編集 | キャッシュ再読込] (Shift + R) か [編集 | 全てのサムネイルを再
    作成] (Ctrl + R) をすると反映されます。

    ここで、"キャッシュの再読込"を行った場合、キャッシュの画像が新しいサムネイ
    ルサイズに拡大(縮小)して表示されます。縮小の場合はよいのですが、拡大の場合、
    ドットが荒くなります。これを避けたい場合、"全てのサムネイルを再作成"してく
    ださい。新しいサイズでキャッシュが作り直されるため、ドットが荒くなることは
    ありません。

    サムネイルサイズはタブごとの値で、タブを切り替えるとそのタブの値が表示され
    ます。新しいウィンドウや空のタブでは [設定 | サムネイルウィンドウ | サムネ
    イルビュー | サムネイルサイズ] の値に戻ります。[設定 | サムネイルウィンド
    ウ] の「終了時にウィンドウの状態を保存する」が ON (デフォルト) なら、終了
    した時のツールバーの値がこの設定に保存され、次からのサイズになります。

[リスト更新]・[キャッシュ再読込]・[全てのサムネイルを再作成]の違いについて
    リスト更新 (Shift + Ctrl + R)
        ディスクとメモリ上の情報の差分のみを更新します。ファイルリストを更新す
        るのみで、サムネイルのリサイズは行いません。

    キャッシュ再読込 (Shift + R)
        全ての情報を破棄して、再度全ての情報をディスクから読み込みます。この時、
        キャッシュが存在する場合はキャッシュから読み込み、無い場合は元の画像か
        ら作成します。キャッシュが存在する場合、サムネイルのリサイズだけ行いま
        す。

        再作成ではなくリサイズですから、保存されていたキャッシュが指定サイズよ
        り小さい場合、単なるサムネイルの拡大となるので、画像が汚くなります。

    全てのサムネイルを再作成 (Ctrl + R)
        全ての情報を破棄して、再度全ての情報をディスクから読み込みます。全て、
        元の画像からサムネイルを再作成します。表示サムネイルサイズの変更が行わ
        れた場合、これを行うのが一番良いと思います。表示している部分から作り直
        し、残りは裏で作り直します。作り直している間は進み具合 (n/N) が表示さ
        れ、ツールバーのストップボタンで止められます。表示位置はそのままです。

カスタムレイアウトについて
    [表示 | レイアウト] で、サムネイルウィンドウの各ビュー (ディレクトリビュー・
    サムネイルビュー・プレビュー) の配置を、レイアウト 0〜4 (Ctrl + 0〜4) から
    選べます。レイアウト 0 がデフォルトです。これらの配置は決まっていて、変更
    できません。

    これ以外の配置にしたい時は「カスタム」を使います。次の操作をすると、レイア
    ウトは自動的に「カスタム」になります。

     ・ [表示 | レイアウト | ウィンドウ構成] で、ウィンドウの分け方 (ペインを
        縦横どちらに分けて、どう組み合わせるか) を選ぶ。

     ・ ビューを別のビューの上へドラッグ & ドロップして、2 つの場所を入れ替え
        る。ドラッグするのは、サムネイルビューのタブ、ディレクトリビューのツー
        ルバー、プレビューのタブ (プレビュー・データ・ノート) です。

    カスタムの配置は、~/.gimv/gimvrc の次の 6 つの項目に保存されます。gimv を
    終了してから直接書き換えることもできます。

     ・ thumbwin_pane1_horizontal (pane1 は水平分割か垂直分割か)

     ・ thumbwin_pane2_horizontal (pane2 について、以下同様)

     ・ thumbwin_pane2_attach_1 (pane2 を pane1 の child1 に張り付けるか,child2
        に張り付けるか)

     ・ thumbwin_widget[0] (pane1 のもう片方に張り付けるウィジェット。1 がディ
        レクトリビュー、2 がサムネイル、3 がプレビュー)

     ・ thumbwin_widget[1] (pane2 の child1)

     ・ thumbwin_widget[2] (pane2 の child2)

    レイアウト 0 〜 4 は、これら 6 つの値があらかじめ決まっているものです。

重複画像の探し方
    [ツール | 重複画像を探す] は、アクティブなタブの画像を次の順に調べ、見つけ
    たものを「完全に同じ」「大きさ違い」と、似ているものの種類 (同じピクセル・
    保存し直し・明るさ・色違い・一部が違う・似ている別の画像) のグループに分け
    ます。探すのは別のスレッドで行うので、その間もウィンドウを操作できます。

     1. 同じファイルを探す: ファイルの大きさ (バイト数) が同じものどうしだけ
        md5 を計算し、md5 も同じなら中身がまったく同じファイルとします。大きさ
        が他と違うファイルは読みません。

     2. 画像を小さく読む: 同じファイルの組からは 1 枚だけ、画像を小さく (128
        ドット程度に) 読み込み、EXIF の向きを直してから、縦横比に関わらず
        32x32 の枠に押し込めて、それぞれの区画の R/G/B の平均を取ります (「指
        紋」と呼ぶソフトもあります)。サムネイルは使わないので、サムネイルビュー
        でまだ読み込んでいない画像も比べられます。

     3. 画像を比べる: 2 枚の指紋の R/G/B の差を平均し (0 〜 1.0)、1.0 からその
        差を引いたものを一致度とします。一致度が設定の値以上なら一致です。全体
        の明るさの合計が離れすぎている画像どうしは一致しようがないので、比べず
        に済ませます。

     4. 種類に分ける: 同じファイルだけのグループは「完全に同じ」です。一致した
        画像が全て同じ縦横比で、同じ大きさのものが 2 つないときは「大きさ違い」
        (同じファイルも含みます)、それ以外は似ているものです。

     5. 似ているものの違いを調べる: 似ているグループの画像どうしを 256 ドット
        程度に縮小して比べ (8 ドット四方の区画ごとの差の平均)、差が全体に小さ
        ければ同じ絵、一部の区画 (5% 未満) だけ大きく違えば「一部が違う」、そ
        れ以外は「似ている別の画像」とします。明るさや色の全体のずれは差し引い
        てから比べます。同じ絵のものはフルサイズで先頭 (残すのによさそうなもの)
        と比べ、差が 0 なら「同じピクセル」、色の平均がずれていれば「明るさ・
        色違い」、JPEG のノイズ程度なら「保存し直し」です。フルサイズで初めて
        分かる小さな違い (署名など) は「一部が違う」になります。同じ絵のまとま
        りが別にあるときは、それぞれのグループに分け、その先頭どうしで「一部が
        違う」「似ている別の画像」のグループを作ります。この分け方の基準は、
        240 万枚の画像で調べた結果に合わせています。

    一致度の値は [設定 | 検索] の「精度」で指定します (初期値 0.97: 97% 以上一
    致していれば一致)。値を下げると、より多くの画像が似ているものに入ります。

    「完全に同じ」「大きさ違い」のグループでは、画素数が最も大きいもの (同じな
    ら容量が大きいもの、さらに同じなら古いもの、パスの短いもの) を「残す」に、
    他を「削除」にしておきます。「大きさ違い」で 2 倍以上大きい画像は、小さい
    画像を拡大しただけのコピーかどうかを調べ、そうなら「拡大したコピーらしい」
    と表示して残す候補から外します (下の「拡大したコピーの見分け方」)。「同じ
    ピクセル」「保存し直し」は残すのによさそうなもの (メタデータの多いもの、
    PNG など画素を保つ形式、画素数の多いもの、JPEG の画質の高いもの) を先頭に
    して「残すおすすめ」と理由を表示しますが、「削除」にはしません。JPEG の画
    質は、ファイルの量子化テーブルが libjpeg のどの画質のものに近いかで推定し
    ます。そのほかの種類は別の画像のこともあるので、全て「残す」にしておきます。
    どれを残すかは人が確かめて決めます。ゴミ箱へは、表示しているグループを「ゴ
    ミ箱へ移動...」で、または全部のグループの「削除」を「全部のグループの削除
    をゴミ箱へ...」でまとめて移します。移す前に、残す画像ともう一度比べます。

    このような作りのため、次のような場合は思ったとおりにならないことがあります。

     1. カラーバランスや明るさが全体的に変わっている画像は一致しにくくなります
        (全ての区画に一様に差が出るため)。

     2. 一部 (上下左右) を切り取った画像は一致しにくくなります (対応しない区画
        どうしを比べてしまうため)。回転・左右反転した画像も一致しません。

     3. 拡大しただけのコピーでも、2 倍より小さい拡大、平らな (細かいところの少
        ない) 画像、強く圧縮した JPEG (画質 70 以下くらい) では見分けられず、
        画素数が大きいので「残す」になります。AI で拡大したもの (waifu2x など)
        は細かいところが作られているので、見分けられないことがあります。

     4. 表示はできても gdk-pixbuf で読めない形式の画像は、「完全に同じ」だけを
        探します。アーカイブの中の画像は対象外です。

    拡大したコピーの見分け方: 普通の拡大 (最近傍・バイリニア・バイキュービック・
    Lanczos など、どのプログラムでも) は、大きい画像の各点を、小さい画像のその
    位置のまわりの点に重みを掛けて足したものにします。そこで、小さい画像から大
    きい画像を予測する最良の重みを半分の点で求め、残りの半分の点で予測の誤差を
    測ります。拡大したコピーなら JPEG の雑音くらいまで予測でき、本当に大きい写
    真は小さい画像にない細かいところが残ります。誤差は、小さい画像を同じ倍率で
    さらに縮めたものから小さい画像を予測した誤差と比べます (写真はどの大きさで
    も似た細かさを持つため、本物ならほぼ同じ、拡大したコピーなら 0.35 倍未満)。
    テスト画像では 2 倍の拡大の 9 割ほどを見分け、本物を拡大したコピーとしたこ

    色・400 ライン、コメントはデータタブに) の読み込みプラグインを追加した

    (「… あと 13 行」) を、選ぶと値の欄の代わりに全文を改行どおりに表示するよ
    うにした (1 行の欄では長いコメントが読みにくかった)。まだ読み込んでいない
